Bootstrap חלק ב': רכיבים שזזים

קרוסלה, חלון קופץ, שאלות נפתחות, לשוניות, תפריט צד והודעות, בלי לכתוב JavaScript
💡 על מה העמוד הזה? במדריך 9 ראינו רכיבים שרק נראים טוב: כפתורים, כרטיסים, טבלאות. כאן נכיר רכיבים שעושים משהו: נפתחים, מתחלפים וקופצים. ל-Bootstrap יש קובץ JavaScript משלו שמפעיל אותם, ולכן לרובם מספיק HTML עם כמה תכונות מיוחדות.

✏️ איך עובדים עם העמוד: בכל עורך קוד אפשר לשנות את הקוד, והתוצאה מתעדכנת מיד בחלון הדפדפן שלידו. אם יש כמה קבצים (index.html, style.css, script.js), לחצו על השם שלהם כדי לעבור ביניהם. ↺ איפוס מחזיר את הדוגמה למצב ההתחלתי, ושני הכפתורים הקטנים לידו מסדרים את העורך והתוצאה זה ליד זה או אחד מעל השני. אי אפשר לשבור כלום, אז תתפרעו!

1. איך זה עובד: תכונות data-bs

📖 data-bs-...תכונות שכותבים בתוך תגית HTML, ו"מדברות" עם ה-JavaScript של Bootstrap. data-bs-toggle אומר מה לעשות (לפתוח חלון, להחליף לשונית), ו-data-bs-target אומר על מי, לפי ה-id שלו עם # לפניו.דוגמה: <button data-bs-toggle="modal" data-bs-target="#myModal"> פירושו "כשלוחצים, פתח את החלון שה-id שלו myModal".

בפרויקט שלכם זה כבר עובד, בלי להתקין כלום: בסוף Views/Shared/_Layout.cshtml יש שורה שטוענת את ה-JavaScript של Bootstrap. בדקו שהיא שם:

<script src="~/lib/bootstrap/dist/js/bootstrap.bundle.min.js"></script>
⚠️ חשוב: כל id פעם אחת בעמוד. אם יש שני רכיבים עם אותו id, הכפתור יפתח את הלא נכון (או אף אחד). זה קורה בעיקר בתוך @foreach, ולכן שם מוסיפים ל-id את המספר של הפריט, למשל id="delete-@product.Id" (סעיף 3).

2. קרוסלה (Carousel): שקופיות מתחלפות

מתאים לבאנר בדף הבית, או לכמה תמונות של אותו מוצר.

חלקמה הוא עושה
carousel slideהעטיפה של הכול. slide = אנימציה של החלקה (carousel-fade = היעלמות).
data-bs-ride="carousel"מתחילה להתחלף לבד כשהעמוד נטען. בלי זה, רק החצים מחליפים.
carousel-item activeשקופית. active = השקופית שמופיעה ראשונה. חייבת להיות בדיוק אחת כזו.
data-bs-interval="3000"כמה זמן כל שקופית מוצגת, באלפיות שנייה (3000 = 3 שניות).
carousel-captionטקסט מעל התמונה. bg-dark bg-opacity-50 rounded-3 נותן לו רקע כהה שקוף למחצה, כדי שיהיה קריא על כל תמונה, ו-mb-3 מרים אותו מעל הנקודות.
d-block w-100התמונה ממלאת את כל הרוחב. כדאי שלכל התמונות יהיה אותו יחס (למשל 800x400), אחרת הגובה "קופץ" בין שקופיות.
carousel-indicators, carousel-control-prev/nextהנקודות והחצים. אפשר למחוק אותם אם לא צריך.

קרוסלה של מוצרים מהמסד

בפרויקט, השקופיות מגיעות מהמסד עם לולאה. הבעיה: רק לשקופית הראשונה צריך active. לכן משתמשים ב-for עם מונה i, ובודקים i == 0:

@model List<Product>

<div id="productsCarousel" class="carousel slide" data-bs-ride="carousel">
    <div class="carousel-inner">
        @for (int i = 0; i < Model.Count; i++)
        {
            var product = Model[i];
            <div class="carousel-item @(i == 0 ? "active" : "")">
                <img src="@product.ImageUrl" class="d-block w-100" alt="@product.Name" />
                <div class="carousel-caption bg-dark bg-opacity-50 rounded-3 py-2 mb-3">
                    <h5>@product.Name</h5>
                    <p>@product.Price ₪</p>
                </div>
            </div>
        }
    </div>
    <button class="carousel-control-prev" type="button" data-bs-target="#productsCarousel" data-bs-slide="prev">
        <span class="carousel-control-prev-icon"></span>
    </button>
    <button class="carousel-control-next" type="button" data-bs-target="#productsCarousel" data-bs-slide="next">
        <span class="carousel-control-next-icon"></span>
    </button>
</div>

@(i == 0 ? "active" : "") פירושו: "אם זו השקופית הראשונה, כתוב active, אחרת אל תכתוב כלום". ImageUrl מגיע ממדריך 16. אם אין לכם תמונות, מחקו את שורת ה-<img> ותנו ל-carousel-item גובה וצבע רקע.

הקרוסלה מופיעה ומתחלפת? אם היא לא מופיעה בכלל, כנראה אף שקופית לא קיבלה active, או שהרשימה ריקה (אין מוצרים במסד).

3. חלון קופץ (Modal)

חלון שמופיע מעל העמוד, והרקע מאחוריו מתכהה. מתאים לפרטים נוספים, לטופס קצר, ובעיקר לשאלה "בטוחים?" לפני מחיקה.

חלקמה הוא עושה
data-bs-toggle="modal" data-bs-target="#infoModal"על הכפתור: פותח את החלון שה-id שלו infoModal.
modal fade + idהחלון עצמו (מוסתר עד שפותחים אותו). fade = מופיע בהדרגה.
modal-header / modal-body / modal-footerכותרת, תוכן וכפתורים בתחתית.
data-bs-dismiss="modal"על כפתור: סוגר את החלון.

בפרויקט: "בטוחים שרוצים למחוק?"

חלון אחד לכל מוצר, בתוך ה-@foreach. בגלל זה ה-id כולל את @product.Id: כך לכל מוצר יש חלון משלו, והכפתור פותח את הנכון.

@foreach (var product in Model)
{
    <tr>
        <td>@product.Name</td>
        <td>
            <button type="button" class="btn btn-sm btn-danger"
                    data-bs-toggle="modal" data-bs-target="#delete-@product.Id">
                מחיקה
            </button>

            <div class="modal fade" id="delete-@product.Id" tabindex="-1">
                <div class="modal-dialog modal-dialog-centered">
                    <div class="modal-content">
                        <div class="modal-header">
                            <h5 class="modal-title">מחיקת מוצר</h5>
                            <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
                        </div>
                        <div class="modal-body">
                            בטוחים שרוצים למחוק את <strong>@product.Name</strong>? אי אפשר לבטל את זה.
                        </div>
                        <div class="modal-footer">
                            <button type="button" class="btn btn-secondary" data-bs-dismiss="modal">ביטול</button>
                            <form asp-action="Delete" asp-route-id="@product.Id" method="post">
                                <button type="submit" class="btn btn-danger">כן, למחוק</button>
                            </form>
                        </div>
                    </div>
                </div>
            </div>
        </td>
    </tr>
}

הטופס שבתוך החלון שולח ל-Action בשם Delete עם POST. ה-Action הזה צריך להיות קיים ב-Controller (בספריית קטעי הקוד: "הוספה, עריכה ומחיקה").

4. שאלות נפתחות (Accordion)

רשימה של כותרות, וכל אחת נפתחת כשלוחצים עליה. מושלם לעמוד "שאלות נפוצות".

חלקמה הוא עושה
data-bs-toggle="collapse" data-bs-target="#q1"על הכותרת: פותח וסוגר את התשובה שה-id שלה q1.
collapse showהתשובה. show = פתוחה כבר בהתחלה.
collapsedעל הכפתור של שאלה סגורה (כדי שהחץ יצביע לכיוון הנכון).
data-bs-parent="#faq"כשפותחים שאלה אחת, האחרות נסגרות.

5. לשוניות (Tabs)

כמה "עמודים" באותו מקום, ומחליפים ביניהם בלי לטעון את העמוד מחדש. למשל בעמוד מוצר: תיאור, מפרט וביקורות.

כמו בקרוסלה: הלשונית הראשונה וגם התוכן הראשון מקבלים active (והתוכן גם show).

6. תפריט שנשלף מהצד (Offcanvas)

חלונית שנכנסת מצד המסך. מתאים לעגלת קניות, לסינון מוצרים, או לתפריט בטלפון.

offcanvas-end = מהסוף של השורה. באתר בעברית (מימין לשמאל) הסוף הוא שמאל, ו-offcanvas-start נכנס מימין.

7. הודעה קופצת (Toast) והסבר צף (Tooltip)

שני רכיבים ש-Bootstrap לא מפעיל לבד, ולכן צריך שורה או שתיים של JavaScript.

Toast: "המוצר נוסף לעגלה"

bootstrap.Toast.getOrCreateInstance(...) לוקח את ה-div של ההודעה, ו-.show() מציג אותה. אחרי 5 שניות היא נעלמת לבד.

Tooltip: הסבר קטן כשהעכבר מעל

בפרויקט, את שלוש השורות של ה-JavaScript שמים פעם אחת ב-wwwroot/js/site.js, וכל כפתור עם data-bs-toggle="tooltip" באתר יקבל הסבר.

8. תוספות קטנות שעושות הרבה

אלה לא זזים, אבל הם הופכים אתר לנראה מקצועי, וכולם עובדים עם CSS בלבד:

רכיבclass עיקרימתי
Badgebadge text-bg-dangerמספר על אייקון (פריטים בעגלה), תגית "חדש" או "מבצע".
Spinnerspinner-borderכשמשהו נטען.
Progressprogress + progress-barכמה הושלם: שלבי הרשמה, ציון.
Floating labelform-floatingטפסי הרשמה והתחברות. שימו לב: ה-<input> לפני ה-<label>, וחייב placeholder.

🔧 אם זה לא עובד

  • לוחצים ולא קורה כלום: בדקו שה-data-bs-target מתחיל ב-#, ושהשם אחרי ה-# זהה בדיוק ל-id (כולל אותיות גדולות וקטנות).
  • אף רכיב לא עובד באתר: בדקו שהשורה של bootstrap.bundle.min.js קיימת בסוף _Layout.cshtml. בכלי המפתחים (F12 ← Console) תופיע שגיאה כמו bootstrap is not defined.
  • הקרוסלה לא מופיעה: אין אף carousel-item עם active, או שיש יותר מאחד.
  • הכפתור בתוך הלולאה פותח את החלון של מוצר אחר: ה-id לא ייחודי. הוסיפו לו @product.Id (סעיף 3).
  • Tooltip או Toast לא מופיעים: הם צריכים את שורות ה-JavaScript מסעיף 7. בלעדיהן, Bootstrap לא מפעיל אותם.

✏️ תרגיל מסכם: עמוד מוצר

  1. בעמוד Details של מוצר, הוסיפו קרוסלה עם 3 תמונות (אפשר מ-placehold.co).
  2. מתחתיה, לשוניות: "תיאור" (עם @Model.Description), "מפרט" ו"משלוחים".
  3. הוסיפו כפתור "הוספה לעגלה" שמציג Toast.
  4. בונוס: ב-Index, החליפו את המחיקה ב-Modal של "בטוחים?" מסעיף 3.

📌 מה למדנו

  • תכונות data-bs-toggle ו-data-bs-target="#id" מפעילות רכיבים בלי לכתוב JavaScript.
  • Carousel, Modal, Accordion, Tabs ו-Offcanvas: רק HTML. Toast ו-Tooltip: צריך שורת JavaScript.
  • בקרוסלה ובלשוניות: בדיוק פריט אחד עם active. מהמסד: @(i == 0 ? "active" : "").
  • בתוך @foreach, כל id צריך להיות ייחודי: מוסיפים @product.Id.
