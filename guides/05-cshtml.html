מדריך 5: מה זה cshtml?

איך כותבים HTML שמשולב בו קוד C#: הסימן @ ותחביר Razor
💡 על מה המדריך הזה? כל העמודים באתר שלנו הם קבצים עם הסיומת .cshtml. אלה קבצי HTML רגילים, עם תוספת אחת: אפשר לכתוב בתוכם גם קוד C#. ככה העמוד יכול להשתנות: להציג את שם המשתמש, רשימה של מוצרים, או "בוקר טוב" רק בבוקר.

מה צריך לפני: פרויקט שיצרתם במדריך 1. מומלץ לקרוא קודם את מדריך 4.

🌐 צריכים לרענן את הבסיס? ב-יסודות HTML יש הסבר קצר ודוגמאות שאפשר לשנות ולראות את התוצאה מיד.

📖 מושג: Razor השם של "השפה" שבה כותבים קבצי cshtml: HTML ועוד C#. השם cshtml בא מ-CS (קיצור של C#) ועוד HTML.

1. הסימן @ פותח קוד C#

בכל מקום בקובץ cshtml, הסימן @ אומר: "מכאן זה כבר לא HTML, זה קוד C#". התוצאה של הקוד נכתבת לתוך העמוד.

מה כותבים בקובץמה רואים בדפדפן
<p>היום: @DateTime.Now</p>היום: (התאריך והשעה של עכשיו)
<p>2 ועוד 3 זה @(2 + 3)</p>2 ועוד 3 זה 5
💡 מתי צריך סוגריים? כשיש רק שם אחד (כמו @DateTime.Now) לא צריך. כשיש חישוב או רווחים (כמו @(2 + 3)) עוטפים בסוגריים, כדי ש-Razor ידע איפה הקוד נגמר.

2. בלוק קוד: ‎@{ ... }

כשרוצים לכתוב כמה שורות C# (למשל להגדיר משתנים), פותחים בלוק עם @{ וסוגרים עם }. הקוד בבלוק רץ, אבל לא מוצג בעמוד. אחר כך אפשר להציג את המשתנים עם @:

@{
    var name = "דנה";
    var age = 16;
}

<p>שלום @name, את בת @age.</p>

בדפדפן יופיע: שלום דנה, את בת 16.

⚠️ טעות נפוצה: אם תשכחו את ה-@ ותכתבו <p>שלום name</p>, יופיע בדפדפן המילה "name" עצמה, ולא "דנה". בלי @, זה סתם טקסט.

ViewData["Title"]: כבר ראיתם אחד כזה

בראש כמעט כל קובץ cshtml בפרויקט יש בלוק כזה:

@{
    ViewData["Title"] = "Home Page";
}

הוא שומר את הכותרת של העמוד, והיא מוצגת בלשונית של הדפדפן. נראה בדיוק איך במדריך 6.

3. תנאים: ‎@if

אפשר להציג חלק מהעמוד רק כשתנאי מתקיים. כותבים @if, ובתוך הסוגריים המסולסלים כותבים HTML רגיל:

@{
    var hour = DateTime.Now.Hour;
}

@if (hour < 12)
{
    <p>בוקר טוב! ☀️</p>
}
else
{
    <p>שלום! 🌙</p>
}

DateTime.Now.Hour נותן את השעה הנוכחית (מספר בין 0 ל-23). לפני 12 בצהריים יוצג "בוקר טוב", ואחרי זה "שלום".

4. לולאות: ‎@foreach

לולאה מאפשרת להציג רשימה שלמה בלי לכתוב כל פריט ביד. זה מה שנשתמש בו בהמשך כדי להציג מוצרים ממסד הנתונים.

@{
    var hobbies = new List<string> { "כדורגל", "ציור", "תכנות" };
}

<ul>
    @foreach (var hobby in hobbies)
    {
        <li>@hobby</li>
    }
</ul>
📖 מושג: List רשימה של פריטים מאותו סוג. List<string> היא רשימה של מחרוזות (טקסטים). הלולאה foreach עוברת על הרשימה פריט אחרי פריט. בכל סיבוב, המשתנה hobby מחזיק פריט אחד, והשורה <li>@hobby</li> יוצרת שורה ברשימה.

בדפדפן תופיע רשימה עם שלוש שורות: כדורגל, ציור, תכנות.

5. בואו ננסה: דף בית משלכם

  • פתחו את הקובץ Views/Home/Index.cshtml.
  • מחקו את כל התוכן שלו (Ctrl+A ואז Delete), והדביקו במקומו את הקוד הבא: 
    @{
    ViewData["Title"] = "דף הבית";
    var myName = "דנה";
    var hour = DateTime.Now.Hour;
    var hobbies = new List<string> { "כדורגל", "ציור", "תכנות" };
}

<div class="text-center">
    @if (hour < 12)
    {
        <h1>בוקר טוב! ☀️</h1>
    }
    else
    {
        <h1>שלום! 🌙</h1>
    }

    <p>קוראים לי @myName, ואלה התחביבים שלי:</p>

    <ul class="list-unstyled">
        @foreach (var hobby in hobbies)
        {
            <li>@hobby</li>
        }
    </ul>

    <p>השעה עכשיו: @DateTime.Now.ToString("HH:mm")</p>
</div>
  • שנו את "דנה" לשם שלכם, ואת התחביבים לתחביבים שלכם. שימו לב לשמור על המירכאות (") סביב כל טקסט.
  • הריצו את האתר.
דף הבית מציג ברכה לפי השעה, את השם שלכם, את רשימת התחביבים ואת השעה הנוכחית.

6. מה הדפדפן באמת מקבל?

בדפדפן, לחצו Ctrl+U (הצגת קוד המקור של העמוד). חפשו את הרשימה שיצרתם.

אין שם שום @foreach ושום @myName! יש רק HTML רגיל, עם שלוש שורות <li> והשם שלכם.
📖 למה זה ככה? קוד ה-C# רץ על השרת, לפני שהעמוד נשלח. השרת מחשב הכול, ושולח לדפדפן רק את התוצאה: HTML נקי. הדפדפן בכלל לא יודע שהיה שם C#. דוגמה: כמו מורה שבודקת מבחן ומחזירה רק את הציון. התלמיד רואה את התוצאה, לא את כל החישובים שהיא עשתה.

7. עוד כמה דברים קטנים

מהאיך
הערה שלא נשלחת לדפדפן@* זו הערה *@. הערת HTML רגילה (<!-- -->) כן נשלחת, ואפשר לראות אותה ב-Ctrl+U.
לכתוב את הסימן @ עצמו כטקסטכותבים פעמיים: @@
@ צמוד לאות לפניוRazor עלול לחשוב שזו כתובת אימייל, ולא יריץ את הקוד. שימו רווח לפני ה-@.

🔧 אם זה לא עובד

  • הרבה קווים אדומים פתאום: כנראה חסר סוגר מסולסל }. לכל { צריך } מתאים. Visual Studio מסמנת את הזוג כשעומדים על אחד מהם.
  • רואים בדפדפן את שם המשתנה במקום הערך: חסר @ לפני המשתנה.
  • שגיאה "The name 'X' does not exist in the current context": המשתנה לא הוגדר, או שיש טעות כתיב. ב-C# יש הבדל בין אותיות גדולות לקטנות: myName ו-MyName הם שני משתנים שונים!
  • חסרה נקודה-פסיק: בתוך בלוק @{ }, כל שורה מסתיימת ב-;. אבל אחרי @name בתוך ה-HTML לא שמים ;.

✏️ תרגיל

  1. הוסיפו לדף הבית משתנה בשם birthYear עם שנת הלידה שלכם, והציגו "בעוד 10 שנים תהיו בני..." עם חישוב. (רמז: @(DateTime.Now.Year - birthYear + 10))
  2. הוסיפו תנאי שלישי: אם השעה אחרי 18, יופיע "ערב טוב". (רמז: else if)
  3. צרו רשימה שנייה, של מקומות שהייתם בהם, והציגו אותה עם @foreach.

📌 מה למדנו

  • קובץ cshtml הוא HTML שאפשר לכתוב בו גם C#, בעזרת הסימן @.
  • @{ } לכמה שורות קוד, @if לתנאים ו-@foreach לרשימות.
  • הקוד רץ על השרת, והדפדפן מקבל רק HTML רגיל.
