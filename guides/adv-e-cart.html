מתקדם ה: עגלת קניות

מיני-פרויקט: הוספה לעגלה, עמוד עגלה עם סכום, ומחיקה ממנה
💡 על מה המדריך הזה? עגלת קניות היא חלק מכמעט כל חנות. נבנה עגלה שזוכרת מה המשתמש הוסיף, בזמן שהוא מסתובב באתר, ומציגה את הסכום לתשלום.

מה צריך לפני: מדריך 13 (מסד נתונים) הוא תנאי מקדים: צריך טבלת מוצרים. זה מדריך ארוך יחסית, שמשלב הרבה ממה שלמדנו. כדאי לעשות Commit לפני שמתחילים.
📖 מושג: Session "זיכרון" קטן שהשרת שומר לכל מבקר בנפרד, כל עוד הוא גולש באתר. מתאים לעגלה: כל משתמש רואה רק את העגלה שלו. חשוב לדעת: ה-Session נמחק כשסוגרים את הדפדפן, או אחרי כ-20 דקות בלי פעילות. בחנות אמיתית, כשמשתמש מזמין, שומרים את ההזמנה במסד נתונים.

1. מפעילים Session

ב-Program.cs שני שינויים:

  • לפני השורה var app = builder.Build();, הוסיפו: 
    builder.Services.AddDistributedMemoryCache();
builder.Services.AddSession();
  • אחרי השורה app.UseRouting();, הוסיפו: 
    app.UseSession();
    (אם אין אצלכם app.UseRouting();, שימו את השורה לפני app.UseAuthorization();.)

2. מודל של פריט בעגלה

קליק ימני על Models ← Add ← Class ← CartItem.cs, ובתוך המחלקה:

public int ProductId { get; set; }
public string Name { get; set; } = "";
public decimal Price { get; set; }
public int Quantity { get; set; }

public decimal Total => Price * Quantity;
מההסבר
Quantityכמה יחידות מהמוצר בעגלה.
Total => Price * QuantityProperty שמחושב לבד: מחיר כפול כמות. אין צורך לשמור אותו.
💡 בלי DbSet ובלי Migration! CartItem הוא מודל שלא נשמר במסד הנתונים, רק ב-Session. מודל לא חייב להיות טבלה.

3. CartController

צרו Controller חדש (Controllers ← Add ← Controller ← MVC Controller - Empty ← CartController.cs), והחליפו את כל מה שבתוך המחלקה ב:

private readonly ApplicationDbContext _context;

public CartController(ApplicationDbContext context)
{
    _context = context;
}

// קריאת העגלה מה-Session
private List<CartItem> GetCart()
{
    var json = HttpContext.Session.GetString("Cart");
    if (json == null)
    {
        return new List<CartItem>();
    }
    return JsonSerializer.Deserialize<List<CartItem>>(json) ?? new List<CartItem>();
}

// שמירת העגלה ב-Session
private void SaveCart(List<CartItem> cart)
{
    HttpContext.Session.SetString("Cart", JsonSerializer.Serialize(cart));
}

// עמוד העגלה
public IActionResult Index()
{
    return View(GetCart());
}

// הוספת מוצר
[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Add(int id)
{
    var product = _context.Products.Find(id);
    if (product == null)
    {
        return NotFound();
    }

    var cart = GetCart();
    var item = cart.FirstOrDefault(c => c.ProductId == id);
    if (item == null)
    {
        cart.Add(new CartItem { ProductId = product.Id, Name = product.Name, Price = product.Price, Quantity = 1 });
    }
    else
    {
        item.Quantity++;
    }

    SaveCart(cart);
    return RedirectToAction("Index");
}

// הסרת מוצר
[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Remove(int id)
{
    var cart = GetCart();
    cart.RemoveAll(c => c.ProductId == id);
    SaveCart(cart);
    return RedirectToAction("Index");
}

// ריקון העגלה
[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Clear()
{
    SaveCart(new List<CartItem>());
    return RedirectToAction("Index");
}

בשמות שיסומנו באדום (ApplicationDbContext, CartItem, JsonSerializer), לחצו Ctrl+. והוסיפו את ה-using.

📖 למה JsonSerializer? Session יודע לשמור רק טקסט. לכן הופכים את רשימת הפריטים לטקסט JSON (Serialize) כששומרים, ובחזרה לרשימה (Deserialize) כשקוראים. את שתי הפעולות עטפנו בפונקציות GetCart ו-SaveCart, כדי לא לכתוב את זה בכל Action.
Actionמה הוא עושה
Addאם המוצר כבר בעגלה, מעלה את הכמות. אחרת, מוסיף אותו עם כמות 1.
Removeמוחק את המוצר מהעגלה (RemoveAll מוחק את כל הפריטים שעונים על התנאי).
Clearשומר עגלה ריקה.

4. עמוד העגלה

קליק ימני על Index ב-CartController ← Add View ← Razor View - Empty ← Index.cshtml:

@model List<CartItem>
@{
    ViewData["Title"] = "העגלה שלי";
}

<h1>🛒 העגלה שלי</h1>

@if (Model.Count == 0)
{
    <div class="alert alert-info">העגלה ריקה.</div>
    <a asp-controller="Products" asp-action="Index" class="btn btn-primary">למוצרים</a>
}
else
{
    <table class="table">
        <thead>
            <tr>
                <th>מוצר</th>
                <th>מחיר</th>
                <th>כמות</th>
                <th>סה"כ</th>
                <th></th>
            </tr>
        </thead>
        <tbody>
            @foreach (var item in Model)
            {
                <tr>
                    <td>@item.Name</td>
                    <td>@item.Price ₪</td>
                    <td>@item.Quantity</td>
                    <td>@item.Total ₪</td>
                    <td>
                        <form asp-action="Remove" asp-route-id="@item.ProductId" method="post">
                            <button type="submit" class="btn btn-sm btn-outline-danger">הסרה</button>
                        </form>
                    </td>
                </tr>
            }
        </tbody>
    </table>

    <h4>לתשלום: @Model.Sum(i => i.Total) ₪</h4>

    <form asp-action="Clear" method="post" class="mt-3">
        <button type="submit" class="btn btn-secondary">ריקון העגלה</button>
    </form>
}

Model.Sum(i => i.Total) הוא LINQ: סכום ה-Total של כל הפריטים.

5. כפתור "הוספה לעגלה"

ברשימת המוצרים (Views/Products/Index.cshtml) או בעמוד הפרטים, הוסיפו ליד כל מוצר:

<form asp-controller="Cart" asp-action="Add" asp-route-id="@product.Id" method="post">
    <button type="submit" class="btn btn-sm btn-success">הוספה לעגלה 🛒</button>
</form>

בעמוד הפרטים (Details.cshtml) כתבו @Model.Id במקום @product.Id.

וקישור לעגלה בתפריט (_Layout.cshtml, מדריך 6):

<li class="nav-item">
    <a class="nav-link text-dark" asp-controller="Cart" asp-action="Index">🛒 העגלה</a>
</li>
הוסיפו כמה מוצרים לעגלה, ומוצר אחד פעמיים. בעגלה רואים כל מוצר עם הכמות, הסכום של כל שורה והסכום הכולל. נסו להסיר מוצר ולרוקן את העגלה.

🔧 אם זה לא עובד

  • "Session has not been configured for this application": חסר AddSession או app.UseSession() ב-Program.cs (סעיף 1).
  • העגלה תמיד ריקה: בדקו ש-app.UseSession() נמצא אחרי app.UseRouting(), ושאחרי כל שינוי קוראים ל-SaveCart(cart).
  • "GetString" מסומן באדום: Ctrl+. יוסיף using Microsoft.AspNetCore.Http;.
  • אחרי זמן מה העגלה התרוקנה: זה צפוי. ה-Session נמחק אחרי כ-20 דקות בלי פעילות, או כשסוגרים את הדפדפן.

✏️ תרגיל

  1. הוסיפו בעגלה כפתורי + ו-− ליד הכמות (רמז: עוד שני Actions, כמו Add ו-Remove, שמשנים את Quantity).
  2. הציגו בתפריט כמה פריטים יש בעגלה, למשל "🛒 העגלה (3)".
  3. אתגר: כפתור "הזמנה" ששומר את ההזמנה במסד הנתונים. צריך שני מודלים חדשים, Order (עם המשתמש והתאריך) ו-OrderItem (מוצר, כמות ומחיר), עם קשר אחד-לרבים ביניהם (מדריך 14). אחרי ההזמנה מרוקנים את העגלה.

📌 מה למדנו

  • Session שומר מידע לכל מבקר בנפרד, כל עוד הוא גולש. מפעילים אותו ב-Program.cs.
  • כדי לשמור רשימה ב-Session, הופכים אותה ל-JSON וחזרה.
  • מודל לא חייב להיות טבלה: CartItem חי רק ב-Session.
  • כל פעולה שמשנה את העגלה היא POST עם הגנה, ואחריה Redirect.
