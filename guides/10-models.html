מדריך 10: מודלים

מחלקה שמייצגת מידע, ואיך מעבירים מידע מה-Controller לעמוד
💡 על מה המדריך הזה? עד עכשיו כל הטקסט בעמודים היה כתוב ישירות ב-HTML. אבל באתר אמיתי מציגים מידע: רשימת מוצרים, פרטים של משתמש, הזמנות. במדריך הזה נגדיר איך נראה "מוצר", ניצור כמה מוצרים, ונציג אותם בטבלה ובעמוד פרטים.

מה צריך לפני: Controller בשם ProductsController עם View בשם Index. אם אין לכם, צרו אותם לפי מדריך 7, סעיף 4. מומלץ לקרוא קודם גם את מדריך 4 (איך אתר MVC עובד).

1. מה זה מודל?

📖 מושג: Model (מודל) מחלקה ב-C# שמתארת סוג אחד של מידע: מה יש לו. מודל לא עושה כלום בעצמו, הוא רק "תבנית" למידע. דוגמה: לכל מוצר בחנות יש מספר מזהה, שם, מחיר ותיאור. אז נגדיר מודל בשם Product עם ארבעת הפרטים האלה. כל מוצר אמיתי (עט, מחברת) הוא "עותק" של התבנית הזאת, עם ערכים משלו.
📖 מושג: Property (תכונה) פרט אחד במודל. נכתב כך: public string Name { get; set; }. יש בו שלושה חלקים: הסוג (string = טקסט), השם (Name), ו-{ get; set; }, שאומר "אפשר לקרוא את הערך ולשנות אותו".

2. יוצרים את המודל Product

  • ב-Solution Explorer, קליק ימני על התיקייה Models ← Add ← Class.
  • תנו שם Product.cs (ביחיד, באות גדולה) ולחצו Add.
  • נפתח קובץ עם public class Product (אם כתוב רק class Product, הוסיפו לפניו public). בין הסוגריים המסולסלים של המחלקה, הדביקו: 
    public int Id { get; set; }
public string Name { get; set; } = "";
public decimal Price { get; set; }
public string? Description { get; set; }

הקובץ יראה בערך כך (השם שאחרי namespace הוא שם הפרויקט שלכם, ואותו לא משנים):

namespace MyProject.Models
{
    public class Product
    {
        public int Id { get; set; }
        public string Name { get; set; } = "";
        public decimal Price { get; set; }
        public string? Description { get; set; }
    }
}
שורההסבר
int Idמספר שלם שמזהה כל מוצר. לכל מוצר מספר אחר. כמו תעודת זהות.
string Name ... = ""טקסט. ה-= "" נותן ערך התחלתי ריק, כדי שהשם לא יהיה "כלום".
decimal Priceמספר עשרוני (כמו 12.90). משתמשים ב-decimal לכסף.
string? Descriptionטקסט. סימן השאלה אומר "מותר שלא יהיה תיאור בכלל".

3. יוצרים מוצרים ב-Controller

עדיין אין לנו מסד נתונים (הוא יגיע במדריך 13), אז בינתיים נשמור את המוצרים ברשימה בתוך ה-Controller.

  • פתחו את Controllers/ProductsController.cs.
  • מחקו את ה-Action בשם Index שכבר קיים, ובמקומו (בתוך המחלקה) הדביקו: 
    private static List<Product> products = new List<Product>
{
    new Product { Id = 1, Name = "עט", Price = 5, Description = "עט כחול" },
    new Product { Id = 2, Name = "מחברת", Price = 12, Description = "מחברת 80 דפים" },
    new Product { Id = 3, Name = "תיק", Price = 150, Description = "תיק גב לבית הספר" }
};

public IActionResult Index()
{
    return View(products);
}
  • המילה Product תסומן בקו אדום, כי ה-Controller לא מכיר את התיקייה Models. עמדו עליה ולחצו Ctrl+., ובחרו את האפשרות שמתחילה ב-using. בראש הקובץ תתווסף השורה using MyProject.Models;, והקו האדום ייעלם.
מההסבר
List<Product>רשימה של מוצרים (ראינו List במדריך 5).
new Product { Id = 1, ... }יוצרים מוצר אחד וממלאים לו ערכים.
staticהרשימה נשמרת כל עוד האתר רץ. בלי static, היא הייתה נוצרת מחדש בכל כניסה לעמוד. (כשעוצרים את האתר, הרשימה חוזרת למצב ההתחלתי. מסד נתונים יפתור את זה.)
return View(products);החדש והחשוב: מחזירים את ה-View, ושולחים אליו את רשימת המוצרים.

4. מציגים את המוצרים בעמוד

פתחו את Views/Products/Index.cshtml, מחקו את כל התוכן והדביקו:

@model List<Product>
@{
    ViewData["Title"] = "מוצרים";
}

<h1>המוצרים שלנו</h1>

<table class="table table-striped">
    <thead>
        <tr>
            <th>שם</th>
            <th>מחיר</th>
            <th></th>
        </tr>
    </thead>
    <tbody>
        @foreach (var product in Model)
        {
            <tr>
                <td>@product.Name</td>
                <td>@product.Price ₪</td>
                <td><a asp-action="Details" asp-route-id="@product.Id">פרטים</a></td>
            </tr>
        }
    </tbody>
</table>
📖 מושג: ‎@model ו-Model השורה הראשונה, @model List<Product>, אומרת לעמוד: "אתה הולך לקבל רשימה של מוצרים". אחר כך, בכל מקום בעמוד, Model (באות גדולה) הוא המידע שה-Controller שלח ב-return View(products). שימו לב להבדל: @model באות קטנה מופיע פעם אחת בראש הקובץ ואומר מה הסוג. Model באות גדולה הוא המידע עצמו.
היכנסו ל-/Products. מופיעה טבלה עם שלושת המוצרים. הוסיפו מוצר רביעי לרשימה ב-Controller, והריצו שוב: הוא יופיע בטבלה בלי שנגעתם ב-View.

5. עמוד פרטים של מוצר אחד

בטבלה יש קישור "פרטים". ה-asp-route-id="@product.Id" מוסיף לכתובת את המספר של המוצר, למשל /Products/Details/2. עכשיו ניצור את העמוד הזה.

ה-Action

ב-ProductsController, מתחת ל-Index, הוסיפו:

public IActionResult Details(int id)
{
    var product = products.FirstOrDefault(p => p.Id == id);
    if (product == null)
    {
        return NotFound();
    }
    return View(product);
}
מההסבר
Details(int id)ה-Action מקבל את המספר מהכתובת. בכתובת /Products/Details/2, המשתנה id יהיה 2.
FirstOrDefault(p => p.Id == id)"חפש ברשימה את המוצר הראשון שה-Id שלו שווה ל-id". אם אין כזה, מקבלים null (כלום).
return NotFound();אם המוצר לא נמצא, מחזירים שגיאה 404 במקום לקרוס.
return View(product);הפעם שולחים ל-View מוצר אחד, לא רשימה.

ה-View

קליק ימני על Details ← Add View ← Razor View - Empty ← שם Details.cshtml. החליפו את התוכן ב:

@model Product
@{
    ViewData["Title"] = Model.Name;
}

<h1>@Model.Name</h1>
<p>@Model.Description</p>
<p><strong>מחיר:</strong> @Model.Price ₪</p>

<a asp-action="Index" class="btn btn-secondary">חזרה לרשימה</a>

הפעם @model Product (מוצר אחד), ולכן כותבים ישר @Model.Name, בלי לולאה.

לחצו "פרטים" ליד אחד המוצרים. נפתח עמוד עם השם, התיאור והמחיר שלו. נסו גם /Products/Details/99: תקבלו 404, כי אין מוצר כזה.

🔧 אם זה לא עובד

  • "The type or namespace name 'Product' could not be found": ב-Controller: חסרה שורת using (סעיף 3, Ctrl+.). ב-View: בדקו שבקובץ Views/_ViewImports.cshtml יש שורה @using MyProject.Models עם שם הפרויקט שלכם.
  • NullReferenceException בעמוד: ה-View מנסה להשתמש ב-Model, אבל ה-Controller לא שלח כלום. בדקו שכתוב return View(products); ולא רק return View();.
  • "The model item passed into the ViewDataDictionary is of type ... but this ViewDataDictionary instance requires ...": הסוג ב-@model לא מתאים למה שה-Controller שלח. ל-Index שולחים רשימה (List<Product>), ל-Details מוצר אחד (Product).
  • אחרי עצירת האתר המוצרים שהוספתם נעלמו: זה צפוי. הרשימה חיה רק בזיכרון. במדריך 13 נשמור אותה במסד נתונים.

✏️ תרגיל

  1. הוסיפו למודל Product תכונה חדשה: public int Stock { get; set; } (כמה יחידות במלאי). תנו לכל מוצר ברשימה ערך, והציגו אותו בטבלה ובעמוד הפרטים.
  2. בעמוד הפרטים, אם המלאי הוא 0, הציגו "אזל מהמלאי" באדום (רמז: @if ממדריך 5, ו-text-danger ממדריך 9).
  3. בונוס: צרו מודל משלכם (למשל Book עם כותרת, סופר ושנה), Controller שמחזיק רשימה של ספרים, ועמוד שמציג אותם.

📌 מה למדנו

  • מודל הוא מחלקה בתיקייה Models שמתארת סוג של מידע, עם Properties.
  • ה-Controller שולח מידע ל-View עם return View(המידע).
  • ה-View מצהיר מה הוא מקבל עם @model, ומשתמש במידע דרך Model.
  • asp-route-id מוסיף מספר לכתובת, וה-Action מקבל אותו כפרמטר int id.
