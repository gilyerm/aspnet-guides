מה זה HTML, CSS ו-JavaScript?

שלוש השפות שכל עמוד אינטרנט בנוי מהן, ומה התפקיד של כל אחת
💡 על מה העמוד הזה? כל עמוד שאתם רואים בדפדפן, כולל האתר שתבנו בפרויקט, בנוי משלוש שפות שעובדות יחד. לפני שנכנסים לפרטים בעמודים הבאים, כאן נראה מה כל אחת עושה, איך הן משתלבות, ואיפה כל אחת נמצאת בפרויקט שלכם.

✏️ איך עובדים עם העמוד: בכל עורך קוד אפשר לשנות את הקוד, והתוצאה מתעדכנת מיד בחלון הדפדפן שלידו. אם יש כמה קבצים (index.html, style.css, script.js), לחצו על השם שלהם כדי לעבור ביניהם. ↺ איפוס מחזיר את הדוגמה למצב ההתחלתי, ושני הכפתורים הקטנים לידו מסדרים את העורך והתוצאה זה ליד זה או אחד מעל השני. אי אפשר לשבור כלום, אז תתפרעו!

1. שלוש שפות, שלושה תפקידים

הדרך הכי פשוטה לזכור: אם עמוד אינטרנט היה גוף, HTML הוא השלד, CSS הוא הבגדים, ו-JavaScript הוא מה שגורם לו לזוז.

שפההתפקידשואלתדוגמה קטנה
HTMLהתוכן והמבנה: כותרות, פסקאות, תמונות, כפתורים, טפסים.מה יש בעמוד?<h1>החנות שלנו</h1>
CSSהעיצוב: צבעים, גדלים, גופנים, רווחים ומיקום.איך זה נראה?h1 { color: purple; }
JavaScriptההתנהגות: מה קורה כשלוחצים, מקלידים או גוללים.מה קורה כש...?alert("שלום!");
📖 דפדפן (Browser)התוכנה שבה גולשים באינטרנט: Chrome, Edge, Firefox. הדפדפן הוא זה שקורא את שלוש השפות ומצייר מהן את העמוד על המסך.דוגמה: כשאתם מריצים את הפרויקט ב-Visual Studio, נפתח דפדפן שמציג את האתר שלכם.
⚠️ JavaScript זה לא Java. למרות השם הדומה, אלה שתי שפות שונות לגמרי. וגם C#, השפה שבה כותבים את ה-Controllers, היא שפה אחרת: היא רצה בשרת, לא בדפדפן (סעיף 4).

2. אותו כרטיס, שלב אחרי שלב

הנה כרטיס מוצר קטן. לחצו על השלבים כדי לראות מה כל שפה מוסיפה. שימו לב: בכל שלב מוסיפים שכבה, ולא מוחקים את מה שהיה.

יש תוכן, אין עיצוב. הדפדפן יודע שיש כאן כותרת, פסקה וכפתור, ומציג אותם בעיצוב הרגיל שלו: שחור על לבן, אחד מתחת לשני. לחצו על הכפתור: לא קורה כלום.

אותו HTML בדיוק, עם CSS. לא הוספנו אף מילה לתוכן. ה-CSS רק אמר לדפדפן איך להציג אותו: רקע, מסגרת מעוגלת, צבעים וגדלים. לחצו על הכפתור: עדיין לא קורה כלום.

ועכשיו הכפתור עובד. ה-JavaScript מחכה ללחיצה, ובכל לחיצה משנה את הטקסט שמתחת לכפתור. לחצו כמה פעמים.

3. נסו בעצמכם

כאן הכרטיס המלא, עם שלוש לשוניות, אחת לכל שפה. שנו משהו בכל לשונית וראו מה משתנה.

שיניתם את המחיר בלשונית HTML והוא השתנה בתוצאה? שיניתם את #68217a בלשונית CSS (למשל ל-tomato) והכפתור החליף צבע? מצוין, הבנתם את החלוקה.

4. מי רץ איפה: שרת ודפדפן

בפרויקט ASP.NET יש עוד שחקן: C#. הוא רץ על השרת (המחשב שמריץ את האתר), ותפקידו להכין את ה-HTML. רק אחרי שהעמוד מוכן הוא נשלח לדפדפן, ושם נכנסים לפעולה CSS ו-JavaScript.

📖 שרת (Server)המחשב שמריץ את האתר ושולח עמודים למי שמבקש אותם. כשאתם מפתחים, השרת הוא המחשב שלכם: Visual Studio מריץ אותו, ולכן הכתובת היא localhost.דוגמה: כשמישהו נכנס לאתר שעלה לאינטרנט, השרת נמצא אי שם בענן, והדפדפן נמצא אצל הגולש.

📌 מה למדנו

  • HTML קובע מה יש בעמוד, CSS קובע איך זה נראה, ו-JavaScript קובע מה קורה כשהמשתמש עושה משהו.
  • כל שפה מוסיפה שכבה, בלי לשנות את האחרות.
  • C# רץ בשרת ובונה את ה-HTML. CSS ו-JavaScript רצים בדפדפן.
  • בפרויקט: HTML ב-Views, CSS ב-wwwroot/css, JavaScript ב-wwwroot/js.
