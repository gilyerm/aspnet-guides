מדריך 8: CSS ו-JS

איפה שמים קבצי עיצוב וסקריפטים, איך מקשרים אותם נכון, ואיך הופכים את האתר לעברית מימין לשמאל
💡 על מה המדריך הזה? כבר יודעים לכתוב CSS ו-JavaScript. כאן נלמד איפה הם נמצאים בפרויקט ASP.NET, ואיך מחברים אותם לעמודים: לכל האתר, או רק לעמוד אחד.

מה צריך לפני: מדריך 6 (Layout ותפריט). הוא תנאי מקדים, כי כל הקישורים לקבצים עוברים דרך ה-Layout. לתרגול כדאי שיהיה לכם גם עמוד "אודות" ממדריך 7.

1. התיקייה wwwroot

📖 מושג: קבצים סטטיים קבצים שהדפדפן מקבל כמו שהם, בלי שהשרת משנה בהם משהו: CSS, JavaScript, תמונות. בפרויקט שלנו, כל הקבצים האלה גרים בתיקייה wwwroot. דוגמה: קובץ cshtml עובר "עיבוד" בשרת (ה-C# שבו רץ). קובץ CSS נשלח לדפדפן בדיוק כמו שהוא.
תיקייהמה יש בה
wwwroot/cssקבצי העיצוב שלכם. כבר יש בה site.css.
wwwroot/jsקבצי ה-JavaScript שלכם. כבר יש בה site.js.
wwwroot/libספריות מוכנות (כמו Bootstrap). לא נוגעים.
wwwroot/imagesלא קיימת עדיין. אם יש לכם תמונות, צרו אותה (קליק ימני על wwwroot ← Add ← New Folder).
📖 מושג: הסימן ~/ בקבצי cshtml, ~/ פירושו "התיקייה wwwroot". דוגמה: ~/css/site.css הוא הקובץ wwwroot/css/site.css, ו-~/images/logo.png הוא wwwroot/images/logo.png.

2. CSS לכל האתר

הקובץ wwwroot/css/site.css כבר מקושר לכל העמודים, דרך השורה הזאת ב-_Layout.cshtml:

<link rel="stylesheet" href="~/css/site.css" asp-append-version="true" />

אז כל מה שתכתבו ב-site.css ישפיע על כל האתר. נסו: פתחו את site.css, והוסיפו בסוף הקובץ:

h1 {
    color: darkblue;
}
הריצו את האתר. כל הכותרות הראשיות (h1) בכל העמודים כחולות.

3. CSS לעמוד אחד בלבד

לפעמים רוצים עיצוב רק לעמוד מסוים. בשביל זה צריך שני דברים: "מקום שמור" ב-Layout, וקישור מהעמוד.

שלב 1: מקום שמור ב-Layout (פעם אחת)

ב-_Layout.cshtml, מצאו את השורה של site.css (מסעיף 2), והוסיפו מתחתיה, עדיין בתוך ה-<head>:

@await RenderSectionAsync("Styles", required: false)
📖 מושג: Section (אזור) "מקום שמור" ב-Layout, שכל עמוד יכול למלא בתוכן משלו, או להשאיר ריק. required: false אומר שעמוד לא חייב למלא אותו. דוגמה: ב-Layout כבר יש Section בשם Scripts (בסוף העמוד). עכשיו הוספנו עוד אחד בשם Styles (בראש העמוד).

שלב 2: יוצרים קובץ CSS

  • קליק ימני על התיקייה wwwroot/css ← Add ← New Item.
  • בשורת החיפוש כתבו Style Sheet, בחרו אותו, תנו שם about.css ולחצו Add.
  • כתבו בקובץ: 
    body {
    background-color: lightyellow;
}

שלב 3: מקשרים מהעמוד

בסוף הקובץ Views/Home/About.cshtml הוסיפו:

@section Styles {
    <link rel="stylesheet" href="~/css/about.css" asp-append-version="true" />
}
עמוד "אודות" צהוב, וכל שאר העמודים לבנים כרגיל.

4. JavaScript

גם כאן יש שתי אפשרויות: לכל האתר (בקובץ wwwroot/js/site.js, שכבר מקושר ב-Layout), או לעמוד אחד. לעמוד אחד לא צריך להוסיף כלום ב-Layout, כי ה-Section בשם Scripts כבר קיים שם.

  • קליק ימני על wwwroot/js ← Add ← New Item ← חפשו JavaScript File, ותנו שם about.js.
  • כתבו בקובץ: 
    document.getElementById("helloBtn").addEventListener("click", function () {
    document.getElementById("message").textContent = "שלום! ה-JavaScript עובד 🎉";
});
  • ב-About.cshtml, הוסיפו כפתור ומקום להודעה (איפשהו באמצע העמוד): 
    <button id="helloBtn" class="btn btn-primary">לחצו עליי</button>
<p id="message"></p>
  • ובסוף הקובץ, ליד ה-Section של ה-Styles: 
    @section Scripts {
    <script src="~/js/about.js" asp-append-version="true"></script>
}
בעמוד "אודות", לחיצה על הכפתור מציגה את ההודעה.
💡 למה ה-JavaScript נטען בסוף העמוד? הדפדפן קורא את העמוד מלמעלה למטה. אם הסקריפט ירוץ לפני שהכפתור נוצר, getElementById("helloBtn") לא ימצא אותו. ה-Section בשם Scripts נמצא בסוף ה-Layout, ולכן כשהסקריפט רץ, כל העמוד כבר קיים.

5. "שיניתי את ה-CSS וזה לא מתעדכן!"

📖 מושג: מטמון (Cache) הדפדפן שומר אצלו עותק של קבצי CSS ו-JS, כדי לא להוריד אותם שוב בכל פעם. לפעמים הוא ממשיך להשתמש בעותק הישן גם אחרי ששיניתם את הקובץ.

בשביל זה יש asp-append-version="true" בכל הקישורים שראינו: הוא מוסיף לכתובת של הקובץ "מספר גרסה" שמשתנה כשהקובץ משתנה, וכך הדפדפן יודע שצריך להוריד אותו מחדש. תמיד הוסיפו אותו לקישורים שלכם.

אם עדיין רואים את הגרסה הישנה, לחצו בדפדפן על Ctrl+Shift+R (רענון מלא, בלי מטמון).

6. עברית: האתר מימין לשמאל

הפרויקט נוצר באנגלית, ולכן הכול מסודר משמאל לימין. כדי להפוך את כל האתר לעברית צריך שני שינויים ב-_Layout.cshtml:

  • בשורה הראשונה אחרי <!DOCTYPE html>, החליפו את <html lang="en"> ב: 
    <html lang="he" dir="rtl">
  • בדקו איזו גרסה של Bootstrap יש בפרויקט: ב-Solution Explorer פתחו את הקובץ wwwroot/lib/bootstrap/dist/css/bootstrap.min.css. בשורה הראשונה כתוב משהו כמו Bootstrap v5.3.3. זכרו את המספר וסגרו את הקובץ (בלי לשנות בו כלום).
  • ב-_Layout.cshtml, מצאו את השורה שמקשרת ל-Bootstrap: 
    <link rel="stylesheet" href="~/lib/bootstrap/dist/css/bootstrap.min.css" />
    והחליפו אותה כולה בשורה הזאת: 
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.rtl.min.css" />
    אם הגרסה בפרויקט שלכם שונה מ-5.3.3, שנו את המספר שאחרי bootstrap@ למספר שמצאתם.
כל האתר מסודר מימין לשמאל: שם האתר בתפריט מימין, הטקסטים מיושרים לימין.
💡 מה עשינו? dir="rtl" אומר לדפדפן שהעמוד מימין לשמאל. bootstrap.rtl.min.css היא גרסה של Bootstrap (ספריית העיצוב של האתר, נכיר אותה במדריך 9) שמותאמת לכיוון הזה. הגרסה הזאת לא מגיעה עם הפרויקט, ולכן לקחנו אותה מ-CDN.
📖 מושג: CDN אתר שמאחסן ספריות מוכנות (כמו Bootstrap), כדי שכל אחד יוכל לקשר אליהן בכתובת אינטרנט, בלי לשמור עותק בפרויקט. החיסרון: הדפדפן צריך חיבור לאינטרנט כדי להוריד את הקובץ. בלי אינטרנט, האתר יעבוד אבל יופיע בלי עיצוב.

7. כלי המפתחים בדפדפן (F12)

כשהאתר רץ, לחצו F12 בדפדפן. נפתח חלון עם כלים שעוזרים להבין מה קורה בעמוד:

לשוניתלמה היא טובה
Elementsלחצו על החץ הקטן בפינה של החלון, ואז על משהו בעמוד. תראו את ה-HTML שלו, ובצד את כל ה-CSS שמשפיע עליו. אפשר גם לשנות שם ערכים ולראות מיד את התוצאה (השינוי זמני, ונעלם ברענון). מעולה לנסות עיצובים לפני שכותבים אותם בקובץ.
Consoleשגיאות JavaScript מופיעות כאן באדום. כפתור שלא עושה כלום? קודם כול מסתכלים כאן.
כאן תבוא תמונה של כלי המפתחים, עם הלשוניות Elements ו-Console מסומנות

🔧 אם זה לא עובד

  • העיצוב לא מופיע בכלל: לחצו F12 ← Console. אם יש שגיאה 404 על הקובץ, השם או הנתיב בקישור לא נכונים. בדקו שהקובץ באמת נמצא ב-wwwroot/css, ושהשם כתוב בדיוק אותו דבר.
  • שגיאה על @section Styles: שכחתם להוסיף את RenderSectionAsync("Styles", ...) ל-Layout (סעיף 3, שלב 1).
  • הכפתור לא עושה כלום: F12 ← Console. שגיאה כמו "Cannot read properties of null" אומרת שה-id בקוד ה-JS לא זהה ל-id בכפתור.
  • אחרי המעבר לעברית, העיצוב של האתר נעלם לגמרי: הדפדפן לא הצליח להוריד את Bootstrap מה-CDN. בדקו שיש חיבור לאינטרנט, ושהכתובת הועתקה בדיוק (F12 ← Console מציג שגיאה אם הכתובת שגויה). אם אין אינטרנט, החזירו זמנית את השורה המקורית.

✏️ תרגיל

  1. הפכו את האתר שלכם לעברית מימין לשמאל (סעיף 6).
  2. בעזרת F12 ← Elements, מצאו את הצבע של התפריט העליון, ונסו צבעים אחרים ישירות בדפדפן. כשמצאתם צבע שאהבתם, כתבו אותו ב-site.css.
  3. צרו קובץ JavaScript לעמוד "צור קשר" (ממדריך 7), עם כפתור שמציג את השעה הנוכחית כשלוחצים עליו. (רמז: new Date().toLocaleTimeString())

📌 מה למדנו

  • קבצי CSS, JS ותמונות גרים ב-wwwroot, ו-~/ מצביע עליה.
  • site.css ו-site.js משפיעים על כל האתר. לעמוד אחד משתמשים ב-@section Styles וב-@section Scripts.
  • תמיד מוסיפים asp-append-version="true", כדי שהדפדפן לא יציג גרסה ישנה.
  • עברית: dir="rtl" ב-Layout, וקישור ל-bootstrap.rtl.min.css מה-CDN.
  • F12 בדפדפן: Elements לעיצוב, Console לשגיאות JavaScript.
