מדריך 1: יצירת פרויקט

שלב אחר שלב – יצירת פרויקט ASP.NET Core MVC עם מערכת משתמשים

יצירת פרויקט חדש

💡 הסבר קצר: בשלב זה ניצור את שלד האתר שלנו. חשוב מאוד להגדיר כבר עכשיו שהאתר יתמוך במערכת משתמשים (הרשמה והתחברות), כדי שסביבת הפיתוח תכין עבורנו את כל הקבצים הדרושים מראש.

מה צריך לפני: Visual Studio 2026 מותקנת, עם הרכיב ASP.NET and web development (מדריך 0).
  • פתחו את Visual Studio ובחרו באפשרות Create a new project.
  • בשורת החיפוש למעלה הקלידו MVC, ובחרו בתבנית ASP.NET Core Web App (Model-View-Controller) (ודאו שיש סמל של C# ליד).
  • לחצו Next, תנו שם לפרויקט (באנגלית, ללא רווחים) ולחצו Next.
  • במסך ההגדרות, בחרו בגרסת ה-Framework העדכנית ביותר שמופיעה ברשימה (מומלץ לבחור בגרסה עם התווית LTS, למשל .NET 10).
  • תחת Authentication type, שנו את ההגדרה מ-None ל-Individual Accounts. (זהו השלב החשוב ביותר!)
  • לחצו על Create.
  • המתינו כמה שניות עד ש-Visual Studio יסיים ליצור את הפרויקט. בסיום, בסרגל הימני (Solution Explorer) יופיעו כל התיקיות והקבצים של האתר.

מה יש בפרויקט?

💡 אל תיבהלו מכמות הקבצים! Visual Studio יצרה עבורנו מבנה מסודר. ב-Solution Explorer (הסרגל בצד) תראו את התיקיות והקבצים. אלה החשובים, ובכל אחד מהם נעבוד במדריכים הבאים:
  • 🌐 wwwroot התיקייה "הציבורית" של האתר. כאן נשמור תמונות, קובצי עיצוב (CSS) וקוד צד-לקוח (JavaScript) שמוצגים ישירות למשתמש.
  • 🧠 Controllers (בקרים) המוח של האתר. המחלקות כאן מקבלות בקשות מהמשתמש (למשל כשהוא לוחץ על כפתור), וקובעות איזה דף להציג לו בתגובה.
  • 📦 Models (מודלים) כאן נכתוב את המחלקות שמייצגות נתונים (למשל: מחלקת 'משתמש' או 'מוצר'). בהמשך, המחלקות האלו יהפכו לטבלאות/מידע בתוך מסד הנתונים שלנו.
  • 🎨 Views (תצוגות) כאן נמצאים כל דפי ה-HTML (אלו שמסתיימים ב-cshtml) שהמשתמש רואה בעיניים.
  • 🗄️ Data תיקייה שמכילה את הקוד שמנהל את הקשר בין האתר שלנו למסד הנתונים. שם נוסיף את רשימת הטבלאות שלנו.
  • ⚙️ appsettings.json קובץ ההגדרות של האתר (למשל, כאן מוגדרת הכתובת של מסד הנתונים).
  • 🚀 Program.cs נקודת ההתחלה של האתר כולו. הקוד הראשון שרץ מאחורי הקלעים כשלוחצים Play.

🗺️ יש עוד קבצים שלא מופיעים כאן, כמו _ViewStart.cshtml, Migrations ו-bin. מה כל אחד מהם עושה, מתי נוגעים בו ואם מותר למחוק: במפת הפרויקט.

הרצת האתר

💡 הסבר קצר: עכשיו נריץ את האתר כדי לוודא שהכל עובד. Visual Studio מפעיל עבורנו שרת קטן על המחשב ופותח את האתר בדפדפן.
  • לחצו על כפתור ההפעלה הירוק (Play) בסרגל העליון של Visual Studio (ליד הכפתור מופיע השם https).
  • בהרצה הראשונה יקפוץ חלון שמבקש לסמוך על אישור האבטחה של האתר (Trust ASP.NET Core SSL Certificate). לחצו Yes, ובחלון האזהרה שיופיע אחריו לחצו שוב Yes.
🎉 אם הכל עבד כראוי, האתר ייפתח בדפדפן עם דף הבית שנוצר כברירת מחדל!
