מדריך 4: איך אתר MVC עובד

התמונה הכללית: מה קורה מהרגע שמקלידים כתובת ועד שהעמוד מופיע
💡 למה המדריך הזה חשוב? בפרויקט יש הרבה תיקיות וקבצים, וקל ללכת לאיבוד. אחרי המדריך הזה תדעו איזה קובץ אחראי על מה, ותבינו למה כשמשנים קובץ מסוים, משתנה עמוד מסוים באתר. כמעט כל מה שנעשה בהמשך נשען על ההבנה הזאת.

מה צריך לפני: פרויקט שיצרתם במדריך 1.

1. שרת ולקוח

📖 מושג: שרת ולקוח הלקוח הוא הדפדפן (Chrome, Edge) שמבקש עמוד. השרת הוא התוכנה שמקבלת את הבקשה, מכינה את העמוד ושולחת אותו בחזרה. האתר שאנחנו בונים ב-Visual Studio הוא השרת. דוגמה: כשאתם נכנסים ליוטיוב, הדפדפן שלכם הוא הלקוח, והמחשבים של גוגל הם השרת. אצלנו, כשמריצים את האתר, גם הלקוח וגם השרת נמצאים על אותו מחשב (זה ה-localhost ממדריך 2).
📖 מושג: בקשה (Request) ההודעה שהדפדפן שולח לשרת: "תביא לי את העמוד בכתובת הזאת". כל לחיצה על קישור, כל הקלדה של כתובת וכל שליחה של טופס היא בקשה.

2. שלושת החלקים: Model, View, Controller

MVC הם ראשי תיבות של שלושת החלקים שמהם בנוי האתר. לכל חלק יש תיקייה משלו בפרויקט:

חלקתיקייהמה הוא עושהבמסעדה
Controller
(בקר)		Controllersמקבל את הבקשה, מחליט מה לעשות, ובוחר איזה עמוד להחזיר.המלצר: מקבל את ההזמנה ומביא את המנה.
Model
(מודל)		Modelsהמידע עצמו: מוצרים, משתמשים, הזמנות. בדרך כלל מגיע ממסד הנתונים.המצרכים במטבח.
View
(תצוגה)		Viewsאיך העמוד נראה: קובץ HTML (עם סיומת cshtml) שהמשתמש רואה.הצלחת המוגשת: איך המנה נראית.

ככה זה נראה כשמישהו נכנס לעמוד:

1. דפדפןמבקש כתובת
←
2. Controllerמקבל את הבקשה
←
3. Modelמביא מידע (אם צריך)
←
4. Viewבונה את העמוד
←
5. דפדפןמציג את העמוד
💡 בינתיים בלי Model: בעמודים הפשוטים (כמו דף הבית) ה-Controller לא צריך שום מידע, ופשוט מחזיר View. את ה-Model נכיר במדריך 10.

3. איך הכתובת קובעת איזה קוד ירוץ

📖 מושג: Action (פעולה) פונקציה בתוך Controller שמטפלת בבקשה אחת. לכל עמוד באתר יש בדרך כלל Action משלו. דוגמה: ב-HomeController יש Action בשם Privacy, והוא אחראי על עמוד הפרטיות.

הכתובת בדפדפן אומרת לאתר לאיזה Controller ולאיזה Action ללכת. החלק הראשון אחרי שם האתר הוא שם ה-Controller, והחלק השני הוא שם ה-Action:

📖 מושג: ניתוב (Routing) הכלל שקובע איך כתובת מתורגמת ל-Controller ול-Action. הוא כתוב בקובץ Program.cs, ונראה כך: 
pattern: "{controller=Home}/{action=Index}/{id?}"
בעברית: "החלק הראשון הוא ה-Controller (ואם אין, Home). החלק השני הוא ה-Action (ואם אין, Index). החלק השלישי הוא מספר מזהה, והוא לא חובה." את ה-id נפגוש כשנרצה להציג פריט מסוים, למשל /Products/Details/5.

4. מסתכלים על הקוד

פתחו את הקובץ Controllers/HomeController.cs. חוץ מכמה שורות נוספות, תמצאו בו קוד כזה:

public class HomeController : Controller
{
    public IActionResult Index()
    {
        return View();
    }

    public IActionResult Privacy()
    {
        return View();
    }
}
השורהמה היא אומרת
public class HomeController : Controller"זו מחלקה בשם HomeController, והיא Controller". השם חייב להסתיים במילה Controller.
public IActionResult Index()Action בשם Index. IActionResult אומר "הפונקציה הזאת מחזירה תשובה לדפדפן".
return View();"תחזיר את ה-View שיש לו אותו שם כמו ה-Action". ב-Action בשם Index, זה הקובץ Index.cshtml.
💡 איפה מחפשים את ה-View? return View() מחפש קובץ בשם ה-Action, בתוך תיקייה בשם ה-Controller (בלי המילה Controller). ל-HomeController וה-Action Privacy, זה Views/Home/Privacy.cshtml. אם הקובץ לא שם, הוא מחפש גם בתיקייה Views/Shared.

5. בואו ננסה

  • פתחו את הקובץ Views/Home/Privacy.cshtml.
  • מתחת לשורה עם <h1>, הוסיפו שורה משלכם: 
    <p>את העמוד הזה הציג ה-Action בשם Privacy!</p>
  • הריצו את האתר, והוסיפו בסוף הכתובת בדפדפן /Home/Privacy. לדוגמה: https://localhost:7123/Home/Privacy.
העמוד מציג את השורה שהוספתם. עכשיו נסו כתובת שלא קיימת, למשל /Home/Banana. תקבלו שגיאה 404 ("העמוד לא נמצא"), כי ב-HomeController אין Action בשם Banana.

🔧 אם זה לא עובד

  • שגיאה 404 (This localhost page can't be found): אין Controller או Action בשם שבכתובת. בדקו שאין טעות כתיב בכתובת.
  • שגיאה "The view 'X' was not found": ה-Action קיים, אבל אין קובץ View מתאים. השגיאה מפרטת את כל המקומות שבהם האתר חיפש את הקובץ. בדקו ששם הקובץ זהה לשם ה-Action, ושהוא בתיקייה הנכונה.
  • השינוי לא מופיע: שמרתם את הקובץ (Ctrl+S)? אם כן, רעננו את הדפדפן, או עצרו את האתר והריצו מחדש.

✏️ תרגיל

בלי להריץ, ענו על השאלות. אחר כך בדקו בעצמכם:

  1. איזה קובץ View יוצג בכתובת /Home?
  2. בכתובת /Products/Details/5, מה שם ה-Controller, מה שם ה-Action, ומה ה-id?
  3. אם תשנו את שם הקובץ Privacy.cshtml ל-Privacy2.cshtml, מה יקרה כשתיכנסו ל-/Home/Privacy? (אחרי שבדקתם, החזירו את השם המקורי!)

📌 מה למדנו

  • Controller מקבל את הבקשה, Model הוא המידע, ו-View הוא איך העמוד נראה.
  • הכתובת /Home/Privacy מריצה את ה-Action בשם Privacy ב-HomeController.
  • return View() מציג את הקובץ Views/שם-ה-Controller/שם-ה-Action.cshtml.
  • כתובת בלי Controller או Action מגיעה ל-Home ול-Index.
