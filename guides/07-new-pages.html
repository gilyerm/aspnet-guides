מדריך 7: עמודים חדשים

שתי דרכים להוסיף עמוד לאתר: ב-Controller קיים, או באזור חדש עם Controller משלו
💡 על מה המדריך הזה? עד עכשיו שינינו עמודים שכבר היו קיימים. עכשיו ניצור עמודים חדשים משלנו. יש שתי דרכים, ונלמד את שתיהן.

מה צריך לפני: פרויקט שיצרתם במדריך 1. מומלץ מאוד לקרוא קודם את מדריך 4 (איך אתר MVC עובד), כי כל המדריך הזה מבוסס עליו.

1. כללי השמות: הכי חשוב במדריך

רוב השגיאות כשיוצרים עמוד חדש הן טעות בשם. השמות של ה-Controller, ה-Action, התיקייה והקובץ חייבים להתאים זה לזה בדיוק:

מההכללדוגמה
Controllerשם באנגלית, מתחיל באות גדולה, מסתיים ב-ControllerProductsController
תיקיית ה-Viewsשם ה-Controller בלי המילה ControllerViews/Products
Actionשם באנגלית, מתחיל באות גדולהAbout

⚠️ אותיות גדולות וקטנות: ב-C# יש הבדל בין About ל-about. תמיד מתחילים שמות של Controller ו-Action באות גדולה, ושומרים על אותה כתיבה בכל המקומות.

3. דרך א: עמוד חדש ב-Controller קיים

ניצור עמוד "אודות" ב-HomeController.

שלב 1: מוסיפים Action

  • פתחו את Controllers/HomeController.cs.
  • מצאו את ה-Action בשם Privacy. מיד אחרי הסוגר המסולסל שסוגר אותו (}), הדביקו את הקוד הבא: 
    public IActionResult About()
{
    return View();
}
⚠️ איפה בדיוק? ה-Action צריך להיות בתוך המחלקה HomeController (בתוך הסוגריים המסולסלים שלה), אבל מחוץ ל-Actions האחרים. הכי בטוח: מיד אחרי ה-} של Privacy.

שלב 2: יוצרים View

  • לחצו קליק ימני על המילה About בקוד שהדבקתם, ובחרו Add View.
  • בחלון שנפתח בחרו Razor View - Empty ולחצו Add.
  • בשדה השם ודאו שכתוב About.cshtml, ולחצו Add.
כאן תבוא תמונה של חלון Add View עם Razor View - Empty מסומן
💡 לא מוצאים Add View בקליק הימני? אפשר גם כך: ב-Solution Explorer, קליק ימני על התיקייה Views/Home ← Add ← View, ואז אותם שלבים.

הקובץ Views/Home/About.cshtml נוצר ונפתח. מחקו את מה שיש בו והדביקו:

@{
    ViewData["Title"] = "אודות";
}

<h1>אודות</h1>
<p>כאן אפשר לספר על האתר ועל מי שבנה אותו.</p>
הריצו את האתר והיכנסו לכתובת /Home/About. העמוד החדש מופיע, עם התפריט וה-Footer (כי הוא נכנס לתוך ה-Layout).

שלב 3: קישור בתפריט

ב-Views/Shared/_Layout.cshtml הוסיפו קישור, כמו שלמדנו במדריך 6:

<li class="nav-item">
    <a class="nav-link text-dark" asp-area="" asp-controller="Home" asp-action="About">אודות</a>
</li>

4. דרך ב: Controller חדש

ניצור אזור חדש באתר: "מוצרים".

שלב 1: יוצרים Controller

  • ב-Solution Explorer, לחצו קליק ימני על התיקייה Controllers ← Add ← Controller.
  • בחרו MVC Controller - Empty ולחצו Add.
  • בשדה השם כתבו ProductsController.cs (חובה שיסתיים ב-Controller!) ולחצו Add.
כאן תבוא תמונה של חלון Add Controller עם MVC Controller - Empty מסומן

נוצר קובץ חדש, ובו Controller עם Action אחד בשם Index:

public class ProductsController : Controller
{
    public IActionResult Index()
    {
        return View();
    }
}
📖 למה דווקא Index? Index הוא ה-Action של ברירת המחדל. בזכותו, הכתובת /Products (בלי Action) מגיעה ל-Products/Index. זה בדיוק כמו דף הבית, שהוא Home/Index.

שלב 2: יוצרים View

  • לחצו קליק ימני על המילה Index בקוד של ה-Controller החדש ← Add View ← Razor View - Empty ← Add.
  • ודאו שהשם הוא Index.cshtml ולחצו Add.
ב-Solution Explorer נוצרה תיקייה חדשה, Views/Products, ובתוכה Index.cshtml. Visual Studio יצרה את התיקייה לבד, עם השם הנכון.

החליפו את תוכן הקובץ ב:

@{
    ViewData["Title"] = "מוצרים";
}

<h1>המוצרים שלנו</h1>
<p>בקרוב תופיע כאן רשימת מוצרים.</p>
היכנסו לכתובת /Products. העמוד החדש מופיע.

שלב 3: עוד עמוד באותו אזור

כדי להוסיף עוד עמוד ל"מוצרים", חוזרים על דרך א, אבל ב-ProductsController: מוסיפים Action (למשל Sale לעמוד מבצעים), ויוצרים לו View. הוא יגיע לתיקייה Views/Products, והכתובת תהיה /Products/Sale.

🔧 אם זה לא עובד

  • "The view 'About' was not found": ה-Action קיים, אבל הקובץ לא נמצא איפה שצריך. השגיאה מציגה את המקומות שבהם האתר חיפש. בדקו את שם הקובץ ואת התיקייה שלו מול הטבלה בסעיף 1.
  • שגיאה 404: האתר לא מצא Controller או Action בשם שבכתובת. בדקו ששם ה-Controller מסתיים ב-Controller, ושה-Action כתוב בדיוק כמו בכתובת.
  • קווים אדומים אחרי שהדבקתם Action: כנראה הדבקתם אותו במקום הלא נכון (בתוך Action אחר, או מחוץ למחלקה). בדקו את הסוגריים המסולסלים.
  • יצרתם View בתיקייה הלא נכונה: אפשר לגרור את הקובץ ב-Solution Explorer לתיקייה הנכונה.

✏️ תרגיל

  1. צרו Controller חדש בשם ContactController, עם עמוד "צור קשר" שבו כתובת אימייל ומספר טלפון (לא אמיתיים).
  2. הוסיפו לו קישור בתפריט.
  3. הוסיפו ל-ProductsController עמוד בשם Sale ("מבצעים"), ובדקו שהוא עובד בכתובת /Products/Sale.

📌 מה למדנו

  • עמוד חדש = Action ב-Controller + קובץ View באותו שם, בתיקייה של ה-Controller.
  • דרך א: מוסיפים Action ל-Controller קיים, וקליק ימני ← Add View.
  • דרך ב: קליק ימני על Controllers ← Add ← Controller ← MVC Controller - Empty. השם חייב להסתיים ב-Controller.
  • רוב השגיאות הן טעויות בשמות. השגיאה עצמה אומרת איפה האתר חיפש.
