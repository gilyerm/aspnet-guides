💡 על מה העמוד הזה? המשך של יסודות JavaScript, למי שכבר יודע למצוא אלמנט, להגיב ללחיצה ולשנות טקסט. כאן נבנה דברים קצת יותר מעניינים: כרטיסים מתוך נתונים, שעון, משחקים קטנים.

1. פונקציות עם פרמטרים

📖 פרמטרערך שמעבירים לפונקציה כשקוראים לה. ככה אותה פונקציה עושה דברים שונים לפי מה שמקבלת.דוגמה: function greet(name) { ... } ואז greet("דנה") או greet("יוסי"). עם return הפונקציה גם מחזירה תוצאה.

2. אובייקטים ו-template literals

📖 אובייקטכמה ערכים שקשורים זה לזה, בתוך { }, כל אחד עם שם. בדיוק כמו מודל ב-C# (מדריך 10).דוגמה: { name: "עט", price: 5 }. ניגשים עם נקודה: product.name.
📖 Template literalמחרוזת בתוך גרשיים הפוכים (`, המקש משמאל ל-1), שאפשר להכניס לתוכה ערכים עם ${...}. נוח מאוד לבנות HTML.דוגמה: `שלום ${name}!` במקום "שלום " + name + "!".
💡 זה הבסיס ל-fetch: כשהשרת מחזיר JSON (מתקדם ד), מקבלים בדיוק מערך של אובייקטים כזה, ובונים ממנו HTML באותה דרך.

3. טיימרים

פונקציהמה היא עושה
setTimeout(function, 2000)מריצה את הפונקציה פעם אחת, אחרי 2000 מילישניות (2 שניות).
setInterval(function, 1000)מריצה את הפונקציה שוב ושוב, כל שנייה.
clearInterval(id)עוצרת setInterval.
📖 מה זה % ?שארית חלוקה. (i + 1) % 4 עובר 1, 2, 3, 0, 1, 2... כך המצגת חוזרת להתחלה אחרי התמונה האחרונה.

4. מספרים אקראיים: משחקים קטנים

📖 Math.randomMath.random() נותן מספר אקראי בין 0 ל-1. כדי לקבל מספר שלם בין 1 ל-6: Math.floor(Math.random() * 6) + 1.

6. localStorage: הדפדפן זוכר

📖 localStorageמקום קטן בדפדפן שבו אפשר לשמור טקסט, והוא נשאר גם אחרי רענון או סגירה של הדפדפן. כל משתמש, בדפדפן שלו בלבד.מתאים להעדפות (מצב לילה, גודל טקסט). לא מתאים לנתונים חשובים או משותפים: אלה הולכים למסד הנתונים.
קודמה הוא עושה
localStorage.setItem("theme", "dark")שומר.
localStorage.getItem("theme")קורא (או null אם אין).
localStorage.removeItem("theme")מוחק.

דוגמה: מצב לילה שנשמר. בדוגמה הזאת אין עורך חי, כי העורך בעמוד רץ בסביבה מוגנת שבה localStorage חסום. העתיקו אותה לעמוד בפרויקט שלכם:

<button id="mode">🌙 מצב לילה</button>

<script>
    // בטעינת העמוד: אם נשמר מצב לילה, מפעילים אותו
    if (localStorage.getItem("theme") === "dark") {
        document.body.classList.add("dark");
    }

    document.getElementById("mode").addEventListener("click", function () {
        document.body.classList.toggle("dark");
        var isDark = document.body.classList.contains("dark");
        localStorage.setItem("theme", isDark ? "dark" : "light");
    });
</script>

וב-CSS:

body.dark {
    background-color: #1e1e1e;
    color: #eee;
}
הפעילו מצב לילה, ורעננו את העמוד (או סגרו ופתחו את הדפדפן). מצב הלילה נשאר!

📌 מה למדנו

  • פונקציה עם פרמטרים ו-return עושה דברים שונים לפי מה שמקבלת.
  • מערך של אובייקטים + template literal (`${...}`) = HTML שנבנה מנתונים.
  • setTimeout לפעם אחת, setInterval לחזרה, clearInterval לעצירה.
  • Math.random למשחקים, data- לכפתורים רבים, localStorage להעדפות.
