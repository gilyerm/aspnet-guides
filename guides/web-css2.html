מיקום, משתני צבע, Grid ואנימציות
💡 על מה העמוד הזה? המשך של יסודות CSS, למי שכבר מרגיש בנוח עם סלקטורים, צבעים ו-Box Model. כאן: איך להצמיד דברים למקום, להגדיר צבעים פעם אחת לכל האתר, לבנות פריסות מורכבות, ולהוסיף תנועה.

✏️ איך עובדים עם העמוד: בכל תיבה כחולה אפשר לשנות את הקוד, והתוצאה מתעדכנת מיד בצד. אם יש לשוניות (HTML / CSS / JavaScript), לחצו עליהן כדי לעבור בין הקבצים. ↺ איפוס מחזיר את הדוגמה למצב ההתחלתי. אי אפשר לשבור כלום, אז תתפרעו!

1. משתני CSS: הצבעים של האתר במקום אחד

📖 משתנה CSSשם שמחזיק ערך. מגדירים פעם אחת ב-:root (עם שני מקפים בהתחלה), ומשתמשים עם var(...).ככה, כשרוצים להחליף את הצבע של כל האתר, משנים שורה אחת.
💡 בפרויקט: שימו את ה-:root בראש site.css, והשתמשו במשתנים בכל העיצוב שלכם.

2. מיקום (position)

ערךמה הוא עושהשימוש נפוץ
stickyהאלמנט גולל כרגיל, עד שהוא מגיע לראש המסך, ואז "נדבק" שם.תפריט שתמיד נשאר למעלה.
fixedקבוע במקום על המסך, גם כשגוללים.כפתור צף ("וואטסאפ", "חזרה למעלה").
relative + absoluteabsolute ממקם ביחס להורה הקרוב שיש לו relative.תווית "מבצע!" בפינה של כרטיס.

3. CSS Grid: שורות ועמודות

📖 Gridפריסה בשתי ממדים: מגדירים על העוטף כמה עמודות יהיו, והילדים מסתדרים בתוכן לבד. repeat(3, 1fr) פירושו "3 עמודות ברוחב שווה" (fr = חלק מהמקום הפנוי).מתי Flexbox ומתי Grid? Flexbox לשורה אחת (תפריט, כפתורים). Grid לרשת שלמה (גלריה, לוח).

4. אנימציות

📖 @keyframesמגדירים "תסריט" של תנועה: איך האלמנט נראה בהתחלה (from) ובסוף (to), או באחוזים לאורך הדרך. אחר כך מפעילים אותו עם animation.
חלק ב-animationפירוש
beatשם ה-@keyframes.
1sכמה זמן לוקח סיבוב אחד.
infiniteלחזור בלי סוף. בלי זה, פעם אחת.
linearמהירות קבועה (בלי האטה בהתחלה ובסוף).
⚠️ במידה: אנימציה אחת קטנה מוסיפה חיים. הרבה אנימציות מסיחות את הדעת ומעייפות. השתמשו בזה על דבר אחד שרוצים שישימו אליו לב.

📌 מה למדנו

  • משתני CSS (--name ו-var()): צבעים וגדלים במקום אחד.
  • position: sticky לתפריט, fixed לכפתור צף, relative + absolute לתווית על כרטיס.
  • Grid לרשתות: grid-template-columns: repeat(3, 1fr), ו-auto-fill לגלריה שמתאימה את עצמה.
  • אנימציות עם @keyframes ו-animation, במידה.
