מתקדם ב: חיפוש וסינון

תיבת חיפוש, מיון לפי מחיר וסינון לפי קטגוריה, עם LINQ
💡 על מה המדריך הזה? כשיש עשרות מוצרים, צריך דרך למצוא את מה שמחפשים. נוסיף לרשימת המוצרים חיפוש לפי שם, מיון, וסינון לפי קטגוריה.

מה צריך לפני: מדריך 13 (מסד נתונים) הוא תנאי מקדים. לסינון לפי קטגוריה צריך גם את מדריך 14.
📖 מושג: LINQ דרך לכתוב ב-C# "שאלות" על רשימות ועל מסד נתונים: "תביא רק את מה שמתאים", "תמיין לפי...". כבר השתמשנו בו: FirstOrDefault ו-Include הם LINQ.
פעולהמה היא עושהדוגמה
Whereמסננת: רק מה שעונה על התנאיWhere(p => p.Price < 20)
OrderByממיינת מהקטן לגדולOrderBy(p => p.Price)
OrderByDescendingממיינת מהגדול לקטןOrderByDescending(p => p.Price)
Takeרק הראשוניםTake(5)
Countכמה ישCount()
Contains(על טקסט) האם מכילp.Name.Contains("עט")

1. ה-Controller

ב-ProductsController, החליפו את ה-Index ב:

public IActionResult Index(string? search, string? sort, int? categoryId)
{
    var products = _context.Products.Include(p => p.Category).AsQueryable();

    // חיפוש לפי שם
    if (!string.IsNullOrEmpty(search))
    {
        products = products.Where(p => p.Name.Contains(search));
    }

    // סינון לפי קטגוריה
    if (categoryId != null)
    {
        products = products.Where(p => p.CategoryId == categoryId);
    }

    // מיון
    if (sort == "price")
    {
        products = products.OrderBy(p => p.Price);
    }
    else if (sort == "price_desc")
    {
        products = products.OrderByDescending(p => p.Price);
    }
    else
    {
        products = products.OrderBy(p => p.Name);
    }

    ViewBag.Search = search;
    ViewBag.Categories = _context.Categories.ToList();
    return View(products.ToList());
}

לא עשיתם את מדריך 14? מחקו את .Include(p => p.Category), את בלוק "סינון לפי קטגוריה", את int? categoryId ואת שורת ViewBag.Categories.

מההסבר
Index(string? search, ...)ה-Action מקבל את החיפוש מהכתובת. למשל /Products?search=עט&sort=price. אם אין בכתובת, הערך יהיה null.
AsQueryable()"עוד לא להביא כלום, רק להתחיל לבנות שאלה". כל Where ו-OrderBy מוסיפים לשאלה.
products = products.Where(...)מוסיפים תנאי, רק אם המשתמש באמת חיפש.
ToList() בסוףרק כאן השאלה נשלחת למסד הנתונים, עם כל התנאים ביחד.
ViewBag.Searchמחזירים את מילת החיפוש ל-View, כדי שתישאר בתיבה.

2. תיבת החיפוש

ב-Views/Products/Index.cshtml, מעל הרשימה:

<form asp-action="Index" method="get" class="row g-2 mb-3">
    <div class="col-md-6">
        <input type="text" name="search" value="@ViewBag.Search" class="form-control" placeholder="חיפוש מוצר..." />
    </div>
    <div class="col-md-auto">
        <button type="submit" class="btn btn-primary">חיפוש</button>
        <a asp-action="Index" class="btn btn-outline-secondary">ניקוי</a>
    </div>
</form>
📖 למה method="get"? בטופס GET, השדות נכנסים לכתובת (?search=עט), ולא נשלחים בנפרד כמו ב-POST. זה מתאים לחיפוש: אפשר לשמור את הכתובת או לשלוח אותה לחבר, ולקבל את אותן תוצאות. כאן לא משנים שום מידע, אז אין צורך ב-POST.
חפשו חלק משם של מוצר. מופיעים רק המוצרים המתאימים, והכתובת בדפדפן מסתיימת ב-?search=....

3. קישורי מיון וסינון

מתחת לטופס, קישורים למיון. asp-route-sort מוסיף ?sort=... לכתובת, ו-asp-route-search שומר את החיפוש הנוכחי:

<div class="mb-3">
    מיון:
    <a asp-action="Index" asp-route-sort="name" asp-route-search="@ViewBag.Search">לפי שם</a> |
    <a asp-action="Index" asp-route-sort="price" asp-route-search="@ViewBag.Search">מחיר: מהזול</a> |
    <a asp-action="Index" asp-route-sort="price_desc" asp-route-search="@ViewBag.Search">מחיר: מהיקר</a>
</div>

<div class="mb-3">
    קטגוריה:
    <a asp-action="Index" class="btn btn-sm btn-outline-secondary">הכול</a>
    @foreach (var category in (List<Category>)ViewBag.Categories)
    {
        <a asp-action="Index" asp-route-categoryId="@category.Id" class="btn btn-sm btn-outline-primary">@category.Name</a>
    }
</div>

<p class="text-muted">נמצאו @Model.Count מוצרים</p>
לחיצה על "מחיר: מהזול" ממיינת, לחיצה על קטגוריה מסננת, ושורת הספירה מתעדכנת.

🔧 אם זה לא עובד

  • החיפוש לא מוצא כלום: ה-name="search" בתיבה חייב להיות זהה לשם הפרמטר ב-Action (string? search).
  • חיפוש באנגלית רגיש לאותיות גדולות? ב-SQL Server בדרך כלל לא: pen ימצא גם Pen.
  • שגיאה על ViewBag.Categories בלולאה: שכחתם את השורה ViewBag.Categories = ... ב-Action.

✏️ תרגיל

  1. הוסיפו לטופס שני שדות: מחיר מינימום ומחיר מקסימום, וסננו לפיהם (decimal? minPrice, Where(p => p.Price >= minPrice)).
  2. כשאין תוצאות, הציגו "לא נמצאו מוצרים" במקום רשימה ריקה.
  3. שמרו גם את הקטגוריה הנבחרת כשממיינים (רמז: asp-route-categoryId בקישורי המיון, ו-ViewBag.CategoryId).

📌 מה למדנו

  • LINQ: Where מסנן, OrderBy ממיין, ו-ToList מביא את התוצאה.
  • בונים את השאלה שלב אחרי שלב, ומוסיפים תנאי רק אם המשתמש ביקש אותו.
  • חיפוש עושים בטופס GET, והפרמטרים מגיעים ל-Action מהכתובת.
  • asp-route-X מוסיף פרמטרים לקישור.
