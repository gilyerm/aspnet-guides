יסודות CSS

איך מעצבים: צבעים, רווחים, סידור בשורה, ועמוד שמתאים לטלפון
💡 על מה העמוד הזה? אם HTML הוא השלד, CSS הוא הבגדים: צבעים, גדלים, רווחים ומיקום. Bootstrap (מדריך 9) נותן הרבה עיצוב מוכן, אבל כדי לשנות אותו ולהתאים לאתר שלכם צריך להכיר את הבסיס. איפה שמים את ה-CSS בפרויקט: מדריך 8.

✏️ איך עובדים עם העמוד: בכל תיבה כחולה אפשר לשנות את הקוד, והתוצאה מתעדכנת מיד בצד. אם יש לשוניות (HTML / CSS / JavaScript), לחצו עליהן כדי לעבור בין הקבצים. ↺ איפוס מחזיר את הדוגמה למצב ההתחלתי. אי אפשר לשבור כלום, אז תתפרעו!

1. איך כותבים כלל CSS

📖 כלל CSS"למי" (סלקטור), ואז בסוגריים מסולסלים "מה לשנות" (תכונה: ערך;).דוגמה: h1 { color: red; } פירושו "כל ה-h1 בעמוד, בצבע אדום". אל תשכחו את הנקודה-פסיק בסוף כל שורה!

4. Box Model: רווחים ומסגרת

📖 Box Modelכל אלמנט בעמוד הוא קופסה, עם שלוש "שכבות" סביב התוכן: padding (רווח פנימי), border (מסגרת), ו-margin (רווח חיצוני).הזיזו את הסליידרים וראו מה כל אחד עושה:
התוכן

צבע בהמחשההחלק
🟨 פסים צהוביםmargin: רווח מחוץ למסגרת, בין הקופסה לשכנים שלה. שקוף.
🟦 קו כחול כההborder: המסגרת.
🟦 תכלתpadding והתוכן: הרווח בין המסגרת לתוכן מקבל את צבע הרקע של הקופסה.
💡 קיצורים: margin: 10px; = מכל הצדדים. margin: 10px 20px; = למעלה ולמטה 10, לצדדים 20. margin-top: 10px; = רק למעלה. אותו דבר ב-padding.

6. Flexbox: לסדר דברים בשורה

📖 Flexboxהדרך הכי קלה לסדר כמה דברים אחד ליד השני, ולשלוט ברווחים וביישור. שמים display: flex; על העוטף, והילדים שלו מסתדרים בשורה.
תכונה (על העוטף)ערכים נפוציםמה היא עושה
justify-contentflex-start, center, space-between, space-aroundפיזור לאורך השורה.
align-itemsflex-start, center, flex-endיישור לגובה.
gap10pxרווח בין הילדים.
flex-wrapwrapאם אין מקום, לרדת לשורה הבאה.
💡 ב-Bootstrap: אותו דבר בקלאסים: class="d-flex justify-content-between align-items-center gap-2".

8. עמוד שמתאים לטלפון

📖 Media Queryכלל CSS שחל רק כשהמסך בגודל מסוים. @media (max-width: 600px) { ... } פירושו "רק כשהמסך צר מ-600 פיקסלים".
💡 ב-Bootstrap: זה בדיוק מה ש-col-12 col-md-4 עושה בשבילכם (מדריך 9, סעיף 5).

9. CSS משלכם יחד עם Bootstrap

הדרך הנכונה לשנות עיצוב של Bootstrap: לא לגעת בקבצים של Bootstrap, אלא להוסיף class משלכם ב-site.css. הוא נטען אחרי Bootstrap, ולכן הכלל שלכם "מנצח".

⚠️ אם הכלל שלכם לא עובד: F12 ← Elements, בחרו את האלמנט, ובצד תראו את כל הכללים שחלים עליו. כלל שמחוק בקו הוא כלל ש"הפסיד" לכלל אחר. נסו סלקטור ספציפי יותר (למשל .card .btn-pink).

📌 מה למדנו

  • כלל CSS: סלקטור { תכונה: ערך; }. הסלקטור הנפוץ ביותר הוא class (.name).
  • צבעים וטקסט: color, background-color, font-size, text-align.
  • Box Model: padding בפנים, border מסגרת, margin בחוץ.
  • Flexbox מסדר בשורה, ו-@media מתאים לטלפון.
  • משנים את Bootstrap עם class משלכם ב-site.css, ולא בקבצים שלו.
