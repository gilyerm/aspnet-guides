יסודות CSS

איך מעצבים: צבעים, רווחים, סידור בשורה, ועמוד שמתאים לטלפון
💡 על מה העמוד הזה? אם HTML הוא השלד, CSS הוא הבגדים: צבעים, גדלים, רווחים ומיקום. Bootstrap (מדריך 9) נותן הרבה עיצוב מוכן, אבל כדי לשנות אותו ולהתאים לאתר שלכם צריך להכיר את הבסיס. איפה שמים את ה-CSS בפרויקט: מדריך 8. חדשים בזה? התחילו ב-מה זה HTML, CSS ו-JavaScript?

✏️ איך עובדים עם העמוד: בכל עורך קוד אפשר לשנות את הקוד, והתוצאה מתעדכנת מיד בחלון הדפדפן שלידו. אם יש כמה קבצים (index.html, style.css, script.js), לחצו על השם שלהם כדי לעבור ביניהם. ↺ איפוס מחזיר את הדוגמה למצב ההתחלתי, ושני הכפתורים הקטנים לידו מסדרים את העורך והתוצאה זה ליד זה או אחד מעל השני. אי אפשר לשבור כלום, אז תתפרעו!

1. איך כותבים כלל CSS

📖 כלל CSS"למי" (סלקטור), ואז בסוגריים מסולסלים "מה לשנות" (תכונה: ערך;).דוגמה: h1 { color: red; } פירושו "כל ה-h1 בעמוד, בצבע אדום". אל תשכחו את הנקודה-פסיק בסוף כל שורה!

4. Box Model: רווחים ומסגרת

📖 Box Modelכל אלמנט בעמוד הוא קופסה, עם שלוש "שכבות" סביב התוכן: padding (רווח פנימי), border (מסגרת), ו-margin (רווח חיצוני).הזיזו את הסליידרים וראו מה כל אחד עושה:
התוכן

צבע בהמחשההחלק
🟨 פסים צהוביםmargin: רווח מחוץ למסגרת, בין הקופסה לשכנים שלה. שקוף.
🟦 קו כחול כההborder: המסגרת.
🟦 תכלתpadding והתוכן: הרווח בין המסגרת לתוכן מקבל את צבע הרקע של הקופסה.
💡 קיצורים: margin: 10px; = מכל הצדדים. margin: 10px 20px; = למעלה ולמטה 10, לצדדים 20. margin-top: 10px; = רק למעלה. אותו דבר ב-padding.

6. Flexbox: לסדר דברים בשורה

📖 Flexboxהדרך הכי קלה לסדר כמה דברים אחד ליד השני, ולשלוט ברווחים וביישור. שמים display: flex; על העוטף, והילדים שלו מסתדרים בשורה.

align-itemsflex-start, center, flex-endיישור לגובה.

💡 ב-Bootstrap: אותו דבר בקלאסים: class="d-flex justify-content-between align-items-center gap-2".

7. מצבים: hover ועוד, פינות מעוגלות וצל

תכונהמה היא עושה
:hoverהכלל חל רק כשהעכבר מעל האלמנט.
border-radiusפינות מעוגלות. 50% על ריבוע = עיגול.
box-shadowצל: הזזה לצד, הזזה למטה, טשטוש, צבע.
transitionהשינוי קורה בהדרגה, ולא בבת אחת.
cursor: pointerהעכבר הופך ליד, כמו על קישור.

לא רק hover: עוד מצבים של אלמנט

📖 Pseudo-class (מצב)מילה שמוסיפים לסלקטור אחרי נקודתיים, והכלל חל רק כשהאלמנט במצב הזה. :hover הוא אחד מהם, ויש עוד הרבה.דוגמה: button:active { ... } פירושו "כפתור, רק ברגע שלוחצים עליו".
מצבמתי הוא חלשימוש נפוץ
:hoverהעכבר מעל האלמנט.כפתורים, כרטיסים, שורות בטבלה.
:activeברגע הלחיצה עצמה (כל עוד מחזיקים).כפתור ש"נלחץ פנימה".
:focusהאלמנט שפעיל עכשיו: השדה שמקלידים בו, או כפתור שהגיעו אליו עם Tab.מסגרת צבעונית לשדה בטופס.
:visitedקישור שכבר נכנסו אליו.צבע אחר לקישורים שכבר ראו.

8. עיצוב לפי מצב ומיקום: טפסים וטבלאות

אותו רעיון של "מצב" עובד גם על שדות בטופס (מולא נכון? סומן?) ועל המיקום של אלמנט ברשימה (ראשון? אחרון? זוגי?).

טופס שמגיב למשתמש

סלקטורמתי הוא חל
:focusהשדה שמקלידים בו עכשיו.
:user-invalidהמשתמש מילא את השדה (או ניסה לשלוח), והוא לא תקין. למשל שדה required ריק, או אימייל בלי @.
:validהשדה תקין.
:checkedתיבת סימון או radio שסומנו.
:disabledשדה או כפתור עם disabled: אי אפשר להשתמש בהם.
::placeholderהטקסט האפור שמופיע בשדה ריק.
::after / ::beforeמוסיף תוכן אחרי / לפני האלמנט, מתוך ה-CSS, עם content.
💡 :has בשורה של התיבה: .agree:has(:checked) פירושו "התווית .agree, אם יש בתוכה משהו מסומן". כך מעצבים את כל השורה, ולא רק את הריבוע הקטן.

טבלה מפוספסת

סלקטורמה הוא בוחר
:nth-child(even)כל אלמנט במקום זוגי (2, 4, 6...). odd = אי-זוגי.
:nth-child(3)רק האלמנט השלישי.
:first-childהראשון.
:last-childהאחרון.
💡 בפרויקט: כשמציגים טבלה מה-DB עם @foreach (מדריך 10, או "טבלה מהמסד" בספריית קטעי הקוד), אי אפשר לדעת מראש כמה שורות יהיו. :nth-child(even) מפספס אותן לבד, לא משנה כמה. ב-Bootstrap אותו דבר נעשה עם class="table table-striped table-hover".

9. עמוד שמתאים לטלפון

📖 Media Queryכלל CSS שחל רק כשהמסך בגודל מסוים. @media (max-width: 600px) { ... } פירושו "רק כשהמסך צר מ-600 פיקסלים".
💡 ב-Bootstrap: זה בדיוק מה ש-col-12 col-md-4 עושה בשבילכם (מדריך 9, סעיף 5).

10. CSS משלכם יחד עם Bootstrap

הדרך הנכונה לשנות עיצוב של Bootstrap: לא לגעת בקבצים של Bootstrap, אלא להוסיף class משלכם ב-site.css. הוא נטען אחרי Bootstrap, ולכן הכלל שלכם "מנצח".

⚠️ אם הכלל שלכם לא עובד: F12 ← Elements, בחרו את האלמנט, ובצד תראו את כל הכללים שחלים עליו. כלל שמחוק בקו הוא כלל ש"הפסיד" לכלל אחר. נסו סלקטור ספציפי יותר (למשל .card .btn-pink).

📌 מה למדנו

  • כלל CSS: סלקטור { תכונה: ערך; }. הסלקטור הנפוץ ביותר הוא class (.name).
  • צבעים וטקסט: color, background-color, font-size, text-align.
  • Box Model: padding בפנים, border מסגרת, margin בחוץ.
  • מצבים: :hover, :active, :focus, ובטפסים :user-invalid ו-:checked. מיקום: :nth-child(even) לטבלה מפוספסת.
  • Flexbox מסדר בשורה, ו-@media מתאים לטלפון.
  • משנים את Bootstrap עם class משלכם ב-site.css, ולא בקבצים שלו.
