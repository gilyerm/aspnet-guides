מדריך 16: העלאת תמונות

טופס שמעלה קובץ תמונה, שומר אותו באתר, ומציג אותו
💡 על מה המדריך הזה? מוצר בלי תמונה זה משעמם. במדריך הזה נוסיף לטופס הוספת המוצר שדה לבחירת תמונה מהמחשב. התמונה תישמר בתיקייה באתר, ומסד הנתונים ישמור רק את הכתובת שלה.

מה צריך לפני: מדריך 11 (טפסים) ומדריך 13 (מסד נתונים) הם תנאי מקדים: צריך טופס הוספת מוצר שעובד עם מסד הנתונים. כדאי להכיר גם את בדיקת הקלט ממדריך 12.
📖 למה לא שומרים את התמונה במסד הנתונים? אפשר, אבל זה מסובך ומאט את האתר. הדרך המקובלת: את הקובץ עצמו שומרים בתיקייה wwwroot/images (כמו כל קובץ סטטי, מדריך 8), ובמסד הנתונים שומרים רק את הנתיב שלו, למשל /images/products/abc123.jpg.

1. שדה לכתובת התמונה במודל

  • ב-Models/Product.cs, הוסיפו בתוך המחלקה: 
    public string? ImageUrl { get; set; }
    סימן השאלה אומר שמוצר יכול להיות גם בלי תמונה.
  • עצרו את האתר, ובחלון Package Manager Console הריצו (כל שורה בנפרד): 
    Add-Migration AddProductImage
Update-Database

2. הטופס

ב-Views/Products/Create.cshtml צריך שני שינויים:

  • בשורה של <form, הוסיפו enctype, כך שתיראה כך: 
    <form asp-action="Create" method="post" enctype="multipart/form-data">
  • בתוך הטופס, לפני כפתור השמירה, הוסיפו: 
    <div class="mb-3">
    <label class="form-label">תמונה</label>
    <input type="file" name="imageFile" class="form-control" accept="image/*" />
</div>
מההסבר
enctype="multipart/form-data"אומר לדפדפן "הטופס הזה שולח גם קבצים". בלעדיו הקובץ לא נשלח, ולא תקבלו שום שגיאה. זו הטעות הכי נפוצה.
type="file"שדה עם כפתור "בחירת קובץ".
name="imageFile"השם שבו הקובץ יגיע ל-Controller. השם חייב להיות זהה לשם הפרמטר ב-Action.
accept="image/*"בחלון בחירת הקובץ יוצגו רק תמונות. (זה רק לנוחות, ולא מחליף בדיקה בשרת.)

3. שמירת הקובץ ב-Controller

📖 מושג: IFormFile הסוג של קובץ שהגיע מטופס. יש לו שם (FileName), גודל (Length), ופעולה שמעתיקה אותו לקובץ על המחשב (CopyTo).

שלב א: מוסיפים גישה לתיקייה wwwroot

ה-Controller צריך לדעת איפה בדיוק נמצאת התיקייה wwwroot במחשב. ב-ProductsController, שנו את ההתחלה (השדה והבנאי ממדריך 13) כך:

private readonly ApplicationDbContext _context;
private readonly IWebHostEnvironment _env;

public ProductsController(ApplicationDbContext context, IWebHostEnvironment env)
{
    _context = context;
    _env = env;
}

_env.WebRootPath הוא הנתיב המלא לתיקייה wwwroot במחשב.

שלב ב: מאפשרים להציג קבצים שהועלו

פתחו את Program.cs, ומיד לפני השורה app.UseRouting(); הוסיפו:

app.UseStaticFiles();
📖 למה צריך את זה? בפרויקט יש כבר שורה בשם app.MapStaticAssets();, שמגישה לדפדפן את הקבצים שב-wwwroot. אבל היא מכירה רק קבצים שהיו קיימים כשהפרויקט נבנה. תמונה שמשתמש מעלה בזמן שהאתר רץ היא קובץ חדש, ובלי UseStaticFiles הדפדפן יקבל עליה 404.

שלב ג: Create של ה-POST

החליפו את ה-Create עם ה-[HttpPost] ב:

[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Create(Product product, IFormFile? imageFile)
{
    // בדיקה שהקובץ הוא תמונה ולא גדול מדי
    if (imageFile != null)
    {
        var allowed = new[] { ".jpg", ".jpeg", ".png", ".gif", ".webp" };
        var extension = Path.GetExtension(imageFile.FileName).ToLower();

        if (!allowed.Contains(extension))
        {
            ModelState.AddModelError("", "אפשר להעלות רק תמונות (jpg, png, gif, webp)");
        }
        if (imageFile.Length > 2 * 1024 * 1024)
        {
            ModelState.AddModelError("", "התמונה גדולה מדי (עד 2MB)");
        }
    }

    if (!ModelState.IsValid)
    {
        return View(product);
    }

    // שמירת הקובץ בתיקייה wwwroot/images/products
    if (imageFile != null)
    {
        var fileName = Guid.NewGuid().ToString() + Path.GetExtension(imageFile.FileName);
        var folder = Path.Combine(_env.WebRootPath, "images", "products");
        Directory.CreateDirectory(folder);

        var filePath = Path.Combine(folder, fileName);
        using (var stream = new FileStream(filePath, FileMode.Create))
        {
            imageFile.CopyTo(stream);
        }

        product.ImageUrl = "/images/products/" + fileName;
    }

    _context.Products.Add(product);
    _context.SaveChanges();
    return RedirectToAction("Index");
}
⚠️ עשיתם את מדריך 14? אז ב-Create הישן היתה גם שורה של ViewBag.Categories בתוך ה-if (!ModelState.IsValid). החזירו אותה לשם, לפני ה-return View(product);.
מההסבר
IFormFile? imageFileהקובץ מהטופס. סימן השאלה: מותר לא לבחור תמונה, ואז imageFile יהיה null.
Path.GetExtension(...)הסיומת של הקובץ, למשל .jpg.
ModelState.AddModelError("", "...")מוסיף שגיאה משלנו לבדיקת הקלט (מדריך 12). היא תוצג ב-asp-validation-summary בראש הטופס.
2 * 1024 * 10242 מגה-בייט, בבתים.
Guid.NewGuid()מייצר שם ייחודי ואקראי, כמו 3f2a9c.... ככה שני תלמידים שמעלים image.jpg לא דורסים זה את זה.
Directory.CreateDirectory(folder)יוצר את התיקייה אם היא עוד לא קיימת. אם כבר קיימת, לא עושה כלום.
using (var stream = ...) { CopyTo }פותח קובץ חדש במחשב, מעתיק לתוכו את התמונה, וסוגר אותו.
product.ImageUrl = ...שומרים במוצר את הכתובת של התמונה, וזה מה שנכנס למסד הנתונים.
הוסיפו מוצר עם תמונה. ב-Solution Explorer, תחת wwwroot, נוצרה התיקייה images/products ובה קובץ עם שם ארוך ומוזר. (אם לא רואים אותה, לחצו על כפתור "Show All Files" בראש Solution Explorer, או על רענון.)

4. הצגת התמונה

ב-Views/Products/Details.cshtml, הוסיפו מתחת ל-<h1>:

@if (Model.ImageUrl != null)
{
    <img src="@Model.ImageUrl" alt="@Model.Name" class="img-fluid rounded mb-3" style="max-width: 400px;" />
}

img-fluid של Bootstrap דואג שהתמונה לא תצא מהמסך בטלפון.

ברשימה (Index.cshtml) אפשר להוסיף עמודה עם תמונה קטנה. בשורת הכותרות <th></th>, ובתוך הלולאה:

<td>
    @if (product.ImageUrl != null)
    {
        <img src="@product.ImageUrl" alt="" style="height: 50px;" class="rounded" />
    }
</td>
בעמוד הפרטים של המוצר מופיעה התמונה שהעליתם, וברשימה מופיעה גרסה קטנה שלה.
⚠️ תמונות ו-GitHub: התמונות שמעלים נשמרות בתיקיית הפרויקט, ולכן ייכנסו ל-Commit הבא (מדריך 3). זה בסדר לכמה תמונות, אבל אם מעלים הרבה, המאגר יגדל. בנוסף, במחשב אחר התמונות יגיעו עם הפרויקט, אבל המוצרים במסד הנתונים לא (מדריך 13).

🔧 אם זה לא עובד

  • המוצר נשמר, אבל בלי תמונה (imageFile תמיד null): חסר enctype="multipart/form-data" ב-<form>, או שה-name של השדה לא זהה לשם הפרמטר (imageFile).
  • התמונה לא מוצגת (ריבוע שבור): F12 ← Console תראה שגיאה 404 עם הכתובת. קודם כול, ודאו שהוספתם app.UseStaticFiles(); ב-Program.cs (סעיף 3, שלב ב). אחר כך בדקו שהקובץ באמת קיים ב-wwwroot/images/products, ושהכתובת ב-ImageUrl מתחילה ב-/images/ (בלי wwwroot).
  • הודעות השגיאה על התמונה לא מופיעות: חסר <div asp-validation-summary="ModelOnly" class="text-danger"></div> בטופס (מדריך 12).
  • "IWebHostEnvironment could not be found": Ctrl+. על השם יוסיף את ה-using החסר.

✏️ תרגיל

  1. כשאין למוצר תמונה, הציגו תמונת ברירת מחדל. (רמז: else, ותמונה מ-https://placehold.co/400x300?text=No+Image.)
  2. הציגו את המוצרים בעמוד הרשימה ככרטיסים של Bootstrap עם תמונה (מדריך 9, סעיפים 4-5) במקום טבלה.
  3. בונוס: שנו את המגבלה ל-5MB, ובדקו שתמונה גדולה יותר נחסמת עם הודעה בעברית.

📌 מה למדנו

  • את הקובץ שומרים ב-wwwroot, ובמסד הנתונים רק את הכתובת שלו.
  • טופס עם קובץ חייב enctype="multipart/form-data", והקובץ מגיע ל-Controller כ-IFormFile.
  • בודקים סיומת וגודל, ונותנים לקובץ שם ייחודי עם Guid.
  • מציגים עם <img src="@Model.ImageUrl">, אחרי בדיקה שהכתובת לא null.
