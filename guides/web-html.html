יסודות HTML

התגיות שנשתמש בהן בפרויקט, עם דוגמה חיה לכל אחת
💡 על מה העמוד הזה? HTML הוא השלד של כל עמוד: מה יש בו (כותרת, פסקה, תמונה, טופס). כל קובץ cshtml בפרויקט הוא בעצם HTML, עם תוספות של C# (מדריך 5). כאן נעבור על התגיות שבאמת צריך. חדשים בזה? התחילו ב-מה זה HTML, CSS ו-JavaScript?

✏️ איך עובדים עם העמוד: בכל תיבה כחולה אפשר לשנות את הקוד, והתוצאה מתעדכנת מיד בצד. אם יש לשוניות (HTML / CSS / JavaScript), לחצו עליהן כדי לעבור בין הקבצים. ↺ איפוס מחזיר את הדוגמה למצב ההתחלתי. אי אפשר לשבור כלום, אז תתפרעו!

1. איך נראית תגית

📖 תגית (Tag)מילה בתוך סוגריים משולשים שאומרת לדפדפן "מה זה". לרוב יש תגית פותחת ותגית סוגרת (עם /), והתוכן ביניהן.דוגמה: <p>שלום</p> היא פסקה עם המילה "שלום". חלק מהתגיות לא סוגרים, כמו <br> (ירידת שורה) ו-<img> (תמונה).
📖 תכונה (Attribute)מידע נוסף שכותבים בתוך התגית הפותחת: שם="ערך".דוגמה: <a href="https://google.com">גוגל</a>. ה-href אומר לאן הקישור מוביל.
💡 ומה עם <html>, <head> ו-<body>? בכל עמוד HTML יש את שלושתם. בפרויקט שלנו הם כתובים פעם אחת ב-_Layout.cshtml (מדריך 6), ולכן בקבצי ה-View כותבים רק את מה שבתוך ה-body.

2. כותרות וטקסט

תגיתמה היא
<h1> עד <h6>כותרות. h1 הכי גדולה וחשובה (אחת בעמוד), h6 הכי קטנה.
<p>פסקה.
<strong>טקסט מודגש (חשוב).
<em>טקסט נטוי (הדגשה).
<br>ירידת שורה, בלי לסגור.
<hr>קו מפריד.

3. קישורים ותמונות

תגיתתכונות חשובות
<a> (קישור)href: לאן. target="_blank": פותח בלשונית חדשה.
<img> (תמונה)src: כתובת התמונה. alt: תיאור (חשוב לנגישות). width: רוחב.
💡 בפרויקט: לקישורים בין עמודים באתר משתמשים ב-asp-controller וב-asp-action במקום href (מדריך 6). לתמונות מתיקיית wwwroot כותבים src="~/images/..." (מדריך 8).

4. רשימות

תגיתמה היא
<ul>רשימה עם נקודות (לא ממוספרת).
<ol>רשימה ממוספרת.
<li>פריט אחד ברשימה. תמיד בתוך ul או ol.

5. div, span, class ו-id

📖 div ו-span<div> היא "קופסה" שעוטפת חלק מהעמוד, ומתחילה בשורה חדשה. <span> עוטפת חלק קטן בתוך שורה. לבד הן לא עושות כלום: משתמשים בהן כדי לעצב (CSS) או לבחור חלק בעמוד (JavaScript).
📖 class ו-idclass נותן לתגית "שם קבוצה". הרבה תגיות יכולות לקבל את אותו class. id נותן לתגית שם ייחודי: רק תגית אחת בעמוד.Bootstrap עובד כולו עם class: <button class="btn btn-primary"> (מדריך 9).

6. טבלאות

תגיתמה היא
<table>הטבלה כולה.
<thead> / <tbody>חלק הכותרות / חלק הנתונים.
<tr>שורה (table row).
<th>תא כותרת (מודגש).
<td>תא רגיל (table data).

תכונות של תאים: איחוד תאים

תכונהמה היא עושהדוגמה
colspanהתא תופס כמה עמודות.<td colspan="2">
rowspanהתא תופס כמה שורות.<td rowspan="2">

עיצוב הטבלה: עם CSS

בדוגמאות ישנות באינטרנט תראו תכונות כמו border="1" ו-cellpadding="6" ישירות על <table>. הן עדיין עובדות, אבל הן מיושנות: היום מעצבים טבלה עם CSS, שנותן הרבה יותר שליטה. הנה מה מחליף כל אחת:

תכונה ישנה (לא מומלץ)מה עושים במקום (CSS)
border="1"border: 1px solid #ccc; על th, td, ו-border-collapse: collapse; על table (כדי שלא יהיו קווים כפולים).
cellpadding="6"padding: 6px; על th, td.
cellspacing="0"border-collapse: collapse; על table.
width="100%"width: 100%;
bgcolor="yellow"background-color: yellow;
align="center"text-align: center; (לתוכן התאים).
תכונת CSSמה היא עושה
border-collapse: collapseמאחדת את הקווים של תאים צמודים לקו אחד.
tr:nth-child(even)בוחרת כל שורה זוגית (odd = אי-זוגית). ככה עושים "זברה".
tr:hoverהשורה שהעכבר עליה.
vertical-align: topיישור התוכן בתא לגובה (למעלה / middle / bottom).
💡 בפרויקט: את השורות לא כותבים ביד, אלא בונים בלולאה @foreach מתוך נתונים (מדריך 10). ואפשר לוותר על רוב ה-CSS: class="table table-striped table-hover" של Bootstrap עושה את כל זה בשבילכם (מדריך 9).

7. טפסים

טפסים הם החלק הכי חשוב ב-HTML בשביל הפרויקט: הרשמה, הוספת מוצר, צור קשר. כל שדה הוא <input> עם type אחר.

תגית / typeמה היא
<form>עוטפת את כל השדות. כשלוחצים על כפתור submit, כל מה שבתוכה נשלח.
<label for="...">תווית של שדה. ה-for מחבר אותה ל-id של השדה (לחיצה על התווית מפעילה את השדה).
type="text"שורת טקסט.
type="email", type="password", type="number", type="date"אימייל, סיסמה (מוסתרת), מספר, תאריך.
type="checkbox" / type="radio"תיבת סימון / בחירה אחת מכמה (לכל ה-radio באותה קבוצה אותו name).
<select> + <option>רשימה נפתחת.
<textarea>טקסט ארוך.
<button type="submit">כפתור ששולח את הטופס.
💡 בפרויקט: במקום id ו-name כותבים asp-for="Name", ו-ASP.NET ממלא אותם לבד ומחבר את השדה למודל (מדריך 11). אבל בסוף, בדפדפן, זה בדיוק אותו HTML.

8. תגיות שמתארות את מבנה העמוד

תגיות שמתנהגות כמו <div>, אבל השם שלהן אומר מה התפקיד של החלק. הן עוזרות לקרוא את הקוד, ולמנועי חיפוש ולקוראי מסך להבין את העמוד. כבר תמצאו אותן ב-_Layout.cshtml:

תגיתהתפקיד
<header>החלק העליון (לוגו, תפריט).
<nav>תפריט ניווט.
<main>התוכן הראשי של העמוד.
<section>חלק בעמוד, עם נושא משלו.
<footer>החלק התחתון.

📌 מה למדנו

  • תגית פותחת וסוגרת, ותכונות כמו href ו-src.
  • טקסט: h1-h6, p, strong. קישורים ותמונות: a, img. רשימות: ul/ol/li. טבלאות: table/tr/th/td.
  • div ו-span עוטפים חלקים, ו-class/id נותנים להם שם לעיצוב ול-JavaScript.
  • טפסים: form, label, input עם type, select, textarea, button. בפרויקט asp-for בונה אותם בשבילנו.
