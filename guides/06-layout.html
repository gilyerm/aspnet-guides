מדריך 6: Layout ותפריט

הקובץ שעוטף את כל העמודים באתר, ואיך משנים את התפריט העליון
💡 על מה המדריך הזה? שמתם לב שבכל עמוד באתר יש אותו תפריט למעלה ואותה שורה למטה, אף על פי שבקבצי ה-View לא כתבנו אותם? הם מגיעים מקובץ אחד שעוטף את כל העמודים. במדריך הזה נכיר אותו, ונלמד לשנות את התפריט.

מה צריך לפני: פרויקט שיצרתם במדריך 1. מומלץ לקרוא קודם את מדריך 5 (מה זה cshtml).

1. מה זה Layout?

📖 מושג: Layout (תבנית עמוד) קובץ אחד שמכיל את כל מה שחוזר בכל העמודים: התפריט העליון, השורה התחתונה, קבצי העיצוב. כל עמוד באתר "נכנס" לתוך האמצע שלו. דוגמה: כמו מסגרת של תמונה. המסגרת (Layout) תמיד אותו דבר, ובפנים מחליפים תמונות (העמודים). רוצים לשנות את המסגרת? משנים פעם אחת, וזה משתנה בכל העמודים.

ה-Layout נמצא בקובץ Views/Shared/_Layout.cshtml. פתחו אותו. הוא ארוך, אבל המבנה שלו פשוט:

<!DOCTYPE html>
<html lang="en">
<head>
    <title>@ViewData["Title"] - MyProject</title>
    <link rel="stylesheet" href="~/lib/bootstrap/dist/css/bootstrap.min.css" />
    <link rel="stylesheet" href="~/css/site.css" asp-append-version="true" />
    ...
</head>
<body>
    <header>
        <nav class="navbar ...">
            ... התפריט העליון ...
        </nav>
    </header>

    <div class="container">
        <main role="main" class="pb-3">
            @RenderBody()
        </main>
    </div>

    <footer class="border-top footer text-muted">
        ... השורה התחתונה ...
    </footer>

    <script src="~/js/site.js" asp-append-version="true"></script>
    @await RenderSectionAsync("Scripts", required: false)
</body>
</html>

(זה קיצור. בקובץ האמיתי יש עוד שורות, ובמקום MyProject מופיע השם של הפרויקט שלכם.)

החלקמה הוא עושה
@ViewData["Title"]כאן נכנסת הכותרת שכל עמוד מגדיר לעצמו (ראינו אותה במדריך 5). היא מופיעה בלשונית של הדפדפן.
<nav>התפריט העליון.
@RenderBody()הכי חשוב: "כאן תיכנס התוכן של העמוד הנוכחי". כשנכנסים לדף הבית, במקום הזה מופיע התוכן של Index.cshtml.
<footer>השורה התחתונה.
@await RenderSectionAsync("Scripts", ...)מקום שבו עמוד יכול להוסיף JavaScript משלו. נשתמש בזה במדריך 8.
⚠️ אל תמחקו את @RenderBody()! בלעדיו אף עמוד לא יוצג, ותקבלו שגיאה.
💡 איך כל עמוד יודע להשתמש ב-Layout? בתיקייה Views יש קובץ קטן בשם _ViewStart.cshtml, ובו השורה Layout = "_Layout";. היא אומרת לכל העמודים להשתמש ב-Layout הזה, אז אין צורך לכתוב את זה בכל עמוד.

2. שינוי שם האתר בתפריט

בצד של התפריט העליון מופיע שם הפרויקט. בואו נחליף אותו בשם יפה יותר:

  • ב-_Layout.cshtml, חפשו (Ctrl+F) את המילה navbar-brand. תמצאו שורה כזאת: 
    <a class="navbar-brand" asp-area="" asp-controller="Home" asp-action="Index">MyProject</a>
  • החליפו רק את הטקסט שבין > ל-</a> (שם הפרויקט) בשם שאתם רוצים, למשל האתר שלי.
  • אותו דבר עשו בשורה עם <title> למעלה: החליפו את שם הפרויקט בשם החדש.
  • שמרו והריצו.
השם החדש מופיע בתפריט וגם בלשונית של הדפדפן, בכל העמודים. נסו לעבור לעמוד Privacy, והשם עדיין שם.

3. קישורים בתפריט

חפשו ב-_Layout.cshtml את המילה nav-item. תמצאו את הקישורים של התפריט. כל קישור נראה כך:

<li class="nav-item">
    <a class="nav-link text-dark" asp-area="" asp-controller="Home" asp-action="Privacy">Privacy</a>
</li>
📖 מושג: Tag Helper (asp-controller, asp-action) במקום לכתוב את הכתובת בעצמכם (href="/Home/Privacy"), כותבים לאיזה Controller ולאיזה Action הקישור מוביל, והאתר בונה את הכתובת לבד. דוגמה: asp-controller="Home" asp-action="Privacy" הופך בדפדפן ל-href="/Home/Privacy". היתרון: אם משהו בכתובות ישתנה, הקישורים יתעדכנו לבד. שימו לב: כותבים Home ולא HomeController.

תרגום הקישורים לעברית

הטקסט שבין > ל-</a> הוא מה שרואים בתפריט. החליפו את Home ב-דף הבית, ואת Privacy ב-פרטיות. אל תשנו את מה שכתוב בתוך asp-controller ו-asp-action, אלה השמות של ה-Controller וה-Action בקוד.

הוספת קישור חדש

כדי להוסיף קישור, מעתיקים בלוק <li> שלם ומשנים בו שלושה דברים: את ה-Controller, את ה-Action ואת הטקסט:

<li class="nav-item">
    <a class="nav-link text-dark" asp-area="" asp-controller="Home" asp-action="About">אודות</a>
</li>
⚠️ שימו לב: הקישור הזה יוביל לשגיאה 404, כי עוד אין עמוד בשם About. במדריך 7 ניצור אותו, וכשתחזרו לכאן הקישור כבר יעבוד.

4. הכפתורים Register ו-Login

בתפריט יש גם קישורים להרשמה ולהתחברות. הם לא כתובים ישירות ב-Layout, אלא בקובץ נפרד שה-Layout מכניס בשורה הזאת:

<partial name="_LoginPartial" />

הקובץ עצמו הוא Views/Shared/_LoginPartial.cshtml. אל תמחקו את השורה הזאת, אחרת לא יהיה איך להירשם ולהתחבר. אפשר לתרגם לעברית את הטקסטים בתוך _LoginPartial.cshtml בדיוק כמו בתפריט (למשל Register ל-הרשמה).

5. השורה התחתונה (Footer)

חפשו <footer. בתוכו יש שורה עם &copy; (הסימן ©) ושם הפרויקט. החליפו את הטקסט במשהו משלכם, למשל:

&copy; 2027 - האתר של גיל

🔧 אם זה לא עובד

  • שגיאה "RenderBody has not been called": מחקתם בטעות את @RenderBody(). החזירו אותו (Ctrl+Z עוזר).
  • קישור בתפריט מוביל ל-404: בדקו שהשמות ב-asp-controller וב-asp-action נכונים, בלי המילה Controller, ושה-Action קיים.
  • התפריט נראה שבור או לא במקום: כנראה נמחק או נוסף בטעות תג (<li>, </a>). בדקו שלכל תג פותח יש תג סוגר. Ctrl+K ואז Ctrl+D מסדר את הקוד ועוזר לראות.
  • הקישורים להרשמה והתחברות נעלמו: בדקו שהשורה <partial name="_LoginPartial" /> עדיין קיימת.

✏️ תרגיל

  1. תרגמו לעברית את כל הטקסטים בתפריט, כולל Register ו-Login (בקובץ _LoginPartial.cshtml).
  2. שנו את שם האתר בתפריט, בלשונית ובשורה התחתונה.
  3. בונוס: בדף הבית (Index.cshtml) שנו את ViewData["Title"], ובדקו מה השתנה בלשונית של הדפדפן.

📌 מה למדנו

  • Views/Shared/_Layout.cshtml עוטף את כל העמודים: תפריט, תוכן ושורה תחתונה.
  • @RenderBody() הוא המקום שבו נכנס התוכן של כל עמוד.
  • קישור בתפריט נכתב עם asp-controller ו-asp-action, והטקסט שלו הוא מה שבין התגים.
  • Register ו-Login נמצאים בקובץ נפרד, _LoginPartial.cshtml.
