מדריך 9: Bootstrap

רכיבים מוכנים שהופכים את האתר ליפה, כמעט בלי לכתוב CSS
💡 על מה המדריך הזה? לעצב אתר מאפס ב-CSS לוקח המון זמן. Bootstrap נותן לנו כפתורים, כרטיסים, טבלאות ופריסה מוכנים. כל מה שצריך זה להוסיף class מתאים לתגית HTML.

מה צריך לפני: פרויקט שיצרתם במדריך 1. כדאי שיהיה לכם עמוד לתרגול, כמו "אודות" ממדריך 7. אם עשיתם את סעיף העברית במדריך 8, הדוגמאות יוצגו מימין לשמאל.

🌐 צריכים לרענן את הבסיס? ב-יסודות CSS יש הסבר קצר ודוגמאות שאפשר לשנות ולראות את התוצאה מיד.

📖 מושג: Bootstrap ספריית CSS (ומעט JavaScript) עם עיצובים מוכנים. היא כבר מותקנת בפרויקט שלכם (בתיקייה wwwroot/lib/bootstrap) ומקושרת לכל העמודים דרך ה-Layout. אין צורך להתקין כלום. דוגמה: במקום לכתוב 10 שורות CSS לכפתור כחול ועגול, כותבים <button class="btn btn-primary"> וזהו.
💡 איך עובדים עם המדריך: כל דוגמה כאן אפשר להעתיק ולהדביק לעמוד שלכם (למשל ל-About.cshtml), ולראות את התוצאה. אחר כך משחקים איתה: משנים צבעים, טקסטים ומספרים.

1. כפתורים וצבעים

<button class="btn btn-primary">ראשי</button>
<button class="btn btn-success">הצלחה</button>
<button class="btn btn-danger">מחיקה</button>
<button class="btn btn-outline-secondary">ביטול</button>

<a class="btn btn-primary" asp-controller="Home" asp-action="Index">קישור שנראה כמו כפתור</a>

כל רכיב ב-Bootstrap מקבל אחד משמות הצבעים האלה:

שםצבעמשתמשים בו ל...
primaryכחולהפעולה הראשית בעמוד
secondaryאפורפעולות משניות
successירוקהצלחה, שמירה, אישור
dangerאדוםמחיקה, שגיאה
warningצהובאזהרה
infoתכלתמידע
light / darkבהיר / כההרקעים

הוספת outline- (כמו btn-outline-danger) נותנת כפתור עם מסגרת בלבד, בלי רקע.

2. הודעות (Alerts)

<div class="alert alert-success">הפרטים נשמרו בהצלחה!</div>
<div class="alert alert-danger">משהו השתבש, נסו שוב.</div>
<div class="alert alert-info">טיפ: אפשר לחפש מוצרים לפי שם.</div>

3. רווחים ויישור

במקום לכתוב margin ו-padding ב-CSS, יש קלאסים קצרים:

קלאסמה הוא עושה
m-3רווח מבחוץ מכל הצדדים (margin). המספר בין 0 ל-5: גדול יותר = רווח גדול יותר.
p-3רווח מבפנים מכל הצדדים (padding).
mt-4 / mb-4רווח רק למעלה (t = top) / רק למטה (b = bottom).
text-centerטקסט במרכז.
text-primaryטקסט בצבע primary (עובד עם כל שמות הצבעים).
bg-lightרקע בצבע light (עובד עם כל שמות הצבעים).
rounded / shadowפינות מעוגלות / צל.
<div class="bg-light p-4 mt-4 rounded shadow text-center">
    <h2 class="text-primary">ברוכים הבאים!</h2>
    <p>קופסה עם רקע, רווחים, פינות מעוגלות וצל.</p>
</div>

4. כרטיסים (Cards)

כרטיס הוא קופסה עם תמונה, כותרת, טקסט וכפתור. מושלם להצגת מוצר, כתבה או חבר צוות:

<div class="card" style="width: 18rem;">
    <img src="https://placehold.co/300x200" class="card-img-top" alt="תמונה">
    <div class="card-body">
        <h5 class="card-title">שם המוצר</h5>
        <p class="card-text">תיאור קצר של המוצר.</p>
        <a href="#" class="btn btn-primary">לפרטים</a>
    </div>
</div>
💡 התמונה: placehold.co הוא אתר שמחזיר תמונה אפורה בגודל שמבקשים, כדי שיהיה משהו להציג. כשיהיו לכם תמונות משלכם, שימו אותן ב-wwwroot/images ושנו ל-src="~/images/שם-התמונה.jpg".

5. פריסה: שורות ועמודות (Grid)

כדי לסדר דברים זה לצד זה (למשל שלושה כרטיסים בשורה), משתמשים ברשת של Bootstrap:

📖 מושג: Grid (רשת) כל שורה (row) מחולקת ל-12 חלקים שווים. כל עמודה (col-) אומרת כמה חלקים מתוך ה-12 היא תופסת. דוגמה: col-4 תופסת 4 מתוך 12, כלומר שליש. שלוש עמודות של col-4 ממלאות שורה. col-6 היא חצי, ו-col-12 היא כל השורה. 
<div class="row">
    <div class="col-12 col-md-4 mb-3">
        <div class="card p-3">כרטיס 1</div>
    </div>
    <div class="col-12 col-md-4 mb-3">
        <div class="card p-3">כרטיס 2</div>
    </div>
    <div class="col-12 col-md-4 mb-3">
        <div class="card p-3">כרטיס 3</div>
    </div>
</div>
📖 למה כתוב גם col-12 וגם col-md-4? זה מה שהופך את האתר למתאים לטלפון. col-12 אומר "במסך קטן (טלפון), כל כרטיס תופס שורה שלמה". col-md-4 אומר "ממסך בינוני ומעלה (מחשב), כל כרטיס תופס שליש". כך בטלפון הכרטיסים אחד מתחת לשני, ובמחשב שלושה בשורה.
הדביקו את הדוגמה בעמוד והריצו. עכשיו הקטינו את חלון הדפדפן לרוחב צר: הכרטיסים יירדו אחד מתחת לשני.

6. טבלאות

<table class="table table-striped table-hover">
    <thead>
        <tr>
            <th>שם</th>
            <th>מחיר</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>עט</td>
            <td>5 ₪</td>
        </tr>
        <tr>
            <td>מחברת</td>
            <td>12 ₪</td>
        </tr>
    </tbody>
</table>

table-striped צובע כל שורה שנייה, ו-table-hover מדגיש שורה כשהעכבר עליה. במדריכי הנתונים נמלא טבלה כזאת במידע אמיתי ממסד הנתונים, עם @foreach.

7. איך מוצאים עוד רכיבים

ל-Bootstrap יש עוד עשרות רכיבים: תפריטים נפתחים, חלונות קופצים, טפסים מעוצבים ועוד. כולם מופיעים באתר הרשמי, getbootstrap.com:

  • בתפריט הצד של האתר, תחת Components, בחרו רכיב (למשל Badge או Accordion).
  • בכל עמוד יש דוגמה חיה, ומתחתיה הקוד שלה. לחצו על כפתור ההעתקה שליד הקוד.
  • הדביקו בעמוד שלכם, ושנו את הטקסטים.
⚠️ שימו לב לגרסה: הפרויקט שלכם משתמש ב-Bootstrap 5. אם מצאתם דוגמה באתר אחר שלא עובדת, ייתכן שהיא מגרסה ישנה (3 או 4), שבה הקלאסים היו שונים. עדיף להעתיק מהאתר הרשמי.

🔧 אם זה לא עובד

  • הכפתור נראה כמו כפתור רגיל ואפור: בדקו את שמות הקלאסים. צריך גם btn וגם btn-primary, עם רווח ביניהם.
  • העמודות לא אחת ליד השנייה: כל העמודות (col-) חייבות להיות בתוך <div class="row">, וסכום המספרים בשורה לא יכול לעבור את 12.
  • שום עיצוב של Bootstrap לא עובד: כנראה הקישור ל-Bootstrap ב-_Layout.cshtml נמחק או השתנה (ראו מדריך 8, סעיף 6).

✏️ תרגיל

בנו בעמוד "אודות" את החלקים הבאים:

  1. קופסה עליונה עם רקע בהיר, רווחים וכותרת במרכז, עם שם האתר ומשפט על מה הוא.
  2. שורה של שלושה כרטיסים (אחד מתחת לשני בטלפון), כל אחד מציג תחביב שלכם.
  3. מתחת: כפתור ירוק "צרו קשר" שמוביל לעמוד צור קשר ממדריך 7 (רמז: <a class="btn ..." asp-controller="..." asp-action="...">).

📌 מה למדנו

  • Bootstrap כבר מותקן ומקושר. משתמשים בו בעזרת class.
  • כפתורים: btn btn-צבע. הודעות: alert alert-צבע. טבלאות: table.
  • רווחים: m- ו-p- עם מספר מ-0 עד 5.
  • פריסה: row ובתוכה col-. השורה מחולקת ל-12, ו-col-12 col-md-4 מתאים גם לטלפון וגם למחשב.
  • עוד רכיבים: באתר getbootstrap.com, תחת Components.
